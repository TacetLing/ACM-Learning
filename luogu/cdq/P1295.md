# P1295 [TJOI2011] 书架

## 题目背景

由于最近又购买了很多书，所以你打算在自己的书房做一个新书架，为了照顾整体效果，你希望你的书架的宽度越小越好。

书架背靠墙摆放，宽度就是指书架在垂直于墙面的方向上占据的距离。

## 题目描述

现按一定顺序给出所有要放置于书架上的书，共有 $n$ 本，第 $i$ 本书有一个长度 $h_i$。

书架有若干层，层与层之间的宽度不一定相等，但是一层的宽度不能小于其上所摆放的任何一本书的长度。同时，每层上的书的长度之和不能超过一个给定的参数 $m$，且任何层上的书必须是给出的书的序列中连续的几本。

书架的宽度是所有层的宽度之和，求书架的最小宽度。

## 输入格式

输入的第一行包含两个整数 $n$ 和 $m$。

第 $2$ 到第 $(n + 1)$ 行，每行一个整数，第 $(i + 1)$ 行的整数代表第 $i$ 本书的长度 $h_i$。

## 输出格式

输出一行一个整数表示答案。

## 输入输出样例 #1

### 输入 #1

```
4 6
1
3
3
1
```

### 输出 #1

```
5
```

## 说明/提示

#### 数据规模与约定

- 对于 $30\%$ 的数据，保证 $ n \leq 10^3$。
- 对于 $100\%$ 的数据，保证 $1 \leq n \leq 10^5$，$1 \leq h_i \leq 10^9$，$\max\limits_{i = 1}^{n} h_i \leq m \leq 10^9$。

#### 提示

由于原题题意严重模糊不清，现给出简化版题意：

给出一个长度为 $n$ 的序列 $h$，请将 $h$ 分成若干段，满足每段数字之和都不超过 $m$，最小化每段的最大值之和。


### 思路分析

#### 1. 状态定义与朴素转移
设 $\text{dp}[i]$（$0 \le i \le n$）表示将前 $i$ 本书放到书架上的最小宽度之和，边界条件为 $\text{dp}[0] = 0$，其余初始化为无穷大 $\text{INF}$。

枚举最后一层书架的断点 $j$，即前几层放置前 $j$ 本书，最后一层放置第 $j + 1 \sim i$ 本书（对应 `arr[j + 1 .. i]`）。由于每层书的长度之和不能超过 $m$，合法转移点 $j$ 需满足 $\sum_{k = j + 1}^{i} \text{arr}[k] \le m$。因此有状态转移方程：

$$\text{dp}[i] = \min_{b[i] \le j \le i - 1} \left( \text{dp}[j] + \max_{j + 1 \le k \le i} \text{arr}[k] \right)$$

其中 $b[i]$ 为右端点固定为 $i$ 时满足长度和限制的最左合法分割点（即满足 $\sum_{k = j + 1}^{i} \text{arr}[k] \le m$ 的最小下标 $j$）。

**$b[i]$ 的单调性与预处理**：
因为每本书长度 $\text{arr}[k] \ge 1$，当 $i$ 增大时，若 $j < b[i - 1]$，则 $\sum_{k = j + 1}^{i} \text{arr}[k] > \sum_{k = j + 1}^{i - 1} \text{arr}[k] > m$，故必然有 $b[i] \ge b[i - 1]$（单调不降）。同时题目保证 $\max_{1 \le k \le n} \text{arr}[k] \le m$，即单独放置第 $i$ 本书（$j = i - 1$）必定合法，因此 $b[i] \le i - 1$ 恒成立。借助这一单调性，在 `solve` 中用双指针（滑动窗口 `[j + 1, i]`）即可在 $O(n)$ 时间内预处理出所有的 $b[i]$。

#### 2. CDQ 分治优化 DP（中序遍历与区间解耦）
朴素转移的瓶颈在于 $\max_{j + 1 \le k \le i} \text{arr}[k]$ 将左右端点 $j$ 和 $i$ 耦合在一起，直接枚举需要 $O(n^2)$ 时间。

采用 CDQ 分治（调用 `cdq(0, n)`，必须包含 $0$ 号点，因为 $\text{dp}[0]$ 是“前 $i$ 本书全放第一层”的唯一合法转移起点），对区间 $[l, r]$ 取中点 $\text{mid} = \lfloor (l + r) / 2 \rfloor$，按**中序遍历**顺序执行：
1. 递归 `cdq(l, mid)`：将左半区间 $[l, \text{mid}]$ 内所有 $\text{dp}[j]$ 计算完毕；
2. 跨中点转移：仅考虑 $j \in [l, \text{mid}]$ 对 $i \in [\text{mid} + 1, r]$ 的转移贡献；
3. 递归 `cdq(mid + 1, r)`：处理右半区间内部的转移。

由于状态转移中的 $\min$ 运算满足交换律与结合律，只要保证 $\text{dp}[j]$ 在更新 $\text{dp}[i]$ 时自身已完全算完，先接收来自 $[l, \text{mid}]$ 的更新、再接收来自 $[\text{mid} + 1, i - 1]$ 的更新，最终结果完全正确。

当 $j \in [l, \text{mid}]$ 且 $i \in [\text{mid} + 1, r]$ 时，区间 $(j, i]$ 必然跨过 $\text{mid}$，于是区间最大值可以被彻底解耦为互不相关的两部分：

$$\max_{j + 1 \le k \le i} \text{arr}[k] = \max\Big( \text{sufMax}[j],\ \text{curPreMax}(i) \Big)$$

其中：
* $\text{sufMax}[j] = \max_{j + 1 \le k \le \text{mid}} \text{arr}[k]$（对应代码中的 `suf_max[j]`，特别地 $\text{sufMax}[\text{mid}] = 0$），仅与 $j$ 有关；
* $\text{curPreMax}(i) = \max_{\text{mid} + 1 \le k \le i} \text{arr}[k]$（对应代码中的 `cur_pre_max`），仅与 $i$ 有关。

#### 3. 分类讨论与数据结构维护
观察左半边 $j \in [l, \text{mid}]$：随着 $j$ 增大，后缀区间 $(j, \text{mid}]$ 不断缩短，故 $\text{sufMax}[j]$ 具有**单调不增（从大到小）**的性质。

对于右半边的每一个 $i \in [\text{mid} + 1, r]$，利用 `upper_bound` 配合 `greater<int>()` 在 `suf_max[l .. mid]` 中找到第一个严格小于 $\text{curPreMax}(i)$ 的位置，并将其下标减 $1$ 记为 $p$（$l - 1 \le p \le \text{mid}$）。那么 $p$ 即为左半边中最后一个满足 $\text{sufMax}[j] \ge \text{curPreMax}(i)$ 的下标，$[l, \text{mid}]$ 被分为两种情况：

1. **情况 1（左半边最大值更大：$l \le j \le p$）**
   此时 $\text{sufMax}[j] \ge \text{curPreMax}(i)$，转移代价为 $\text{dp}[j] + \text{sufMax}[j]$（即代码中的 `mk[j]`），完全独立于 $i$。结合当前分治左边界 $l$ 与承重边界 $b[i]$，有效转移区间为 $[\text{ql}, \text{qr}] = [\max(l, b[i]),\ p]$。
   在合并前通过 `calc(l, mid)` 在 $[l, \text{mid}]$ 上对 `mk` 建立 ST 表；若 $\text{ql} \le \text{qr}$，调用 `query(ql, qr)` 在 $O(1)$ 时间内查询区间最小值更新 $\text{dp}[i]$。

2. **情况 2（右半边最大值更大：$p + 1 \le j \le \text{mid}$）**
   此时 $\text{sufMax}[j] < \text{curPreMax}(i)$，转移代价为 $\text{dp}[j] + \text{curPreMax}(i)$。结合边界条件，有效转移区间为 $[\text{low}, \text{mid}] = [\max\{l, b[i], p + 1\},\ \text{mid}]$。
   由于该区间右端点固定为 $\text{mid}$，只需预先倒序求出 $\text{dp}$ 在 $[l, \text{mid}]$ 上的后缀最小值 $\text{sufMinDp}[j] = \min_{j \le k \le \text{mid}} \text{dp}[k]$（对应代码中的 `suf_min_dp[j]`）。若 $\text{low} \le \text{mid}$，直接以 $\text{sufMinDp}[\text{low}] + \text{curPreMax}(i)$ 在 $O(1)$ 时间内更新 $\text{dp}[i]$。

---

### 复杂度分析

* **时间复杂度**：
  * `precompute` 预处理 `lg2` 数组与 `solve` 中双指针预处理 `b` 数组均为 $O(n)$。
  * 在 `cdq(l, r)` 的每一层中，设区间长度为 $K = r - l + 1$：计算 `suf_max`、`suf_min_dp`、`mk` 耗时 $O(K)$；调用 `calc(l, mid)` 构建 ST 表耗时 $O(K \log K)$；扫描右半边对每个 $i$ 执行一次 `upper_bound` 二分查找耗时 $O(\log K)$，区间查询耗时 $O(1)$，共耗时 $O(K \log K)$。
  * 由主定理 $T(n) = 2T(n / 2) + O(n \log n)$，总时间复杂度为 $O(n \log^2 n)$。

* **空间复杂度**：
  * 原数组与一维辅助数组 `arr`、`dp`、`b`、`suf_max`、`suf_min_dp`、`mk`、`lg2` 均占用 $O(n)$ 空间。
  * 全局复用的 ST 表 `st[MAXN][LOGN]` 占用 $O(n \log n)$ 空间；递归栈深度为 $O(\log n)$。
  * 总空间复杂度为 $O(n \log n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

constexpr int MAXN = 100005;
constexpr int LOGN = 19;
constexpr int INF = 1e18;

int n, m, dp[MAXN], suf_max[MAXN], suf_min_dp[MAXN];
int st[MAXN][LOGN];
int lg2[MAXN];
int arr[MAXN];
int b[MAXN];
int mk[MAXN];

void precompute() {
    lg2[1] = 0;
    for (int i = 2; i < MAXN; i++) {
        lg2[i] = lg2[i / 2] + 1;
    }
    return;
}

void calc(int l, int r) {
    for (int i = l; i <= r; i++) {
        st[i][0] = mk[i];
    }
    for (int j = 1; (1 << j) <= r - l + 1; j++) {
        for (int i = l; i + (1 << j) - 1 <= r; i++) {
            st[i][j] = min(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
        }
    }
    return;
}

int query(int L, int R) {
    int k = lg2[R - L + 1];
    return min(st[L][k], st[R - (1 << k) + 1][k]);
}

void cdq(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    cdq(l, mid);

    suf_max[mid] = 0;
    mk[mid] = dp[mid];
    suf_min_dp[mid] = dp[mid];
    for (int j = mid - 1; j >= l; j--) {
        suf_max[j] = max(suf_max[j + 1], arr[j + 1]);
        suf_min_dp[j] = min(suf_min_dp[j + 1], dp[j]);
        mk[j] = dp[j] + suf_max[j];
    }
    calc(l, mid);

    int cur_pre_max = 0;
    int p = l - 1;
    for (int i = mid + 1; i <= r; i++) {
        cur_pre_max = max(cur_pre_max, arr[i]);
        auto it = upper_bound(suf_max + l, suf_max + mid + 1, cur_pre_max, greater<int>());
        p = it - suf_max - 1;

        int ql = max(l, b[i]);
        int qr = p;
        if (ql <= qr) {
            dp[i] = min(dp[i], query(ql, qr));
        }

        int low = max({l, b[i], p + 1});
        if (low <= mid) {
            dp[i] = min(dp[i], suf_min_dp[low] + cur_pre_max);
        }
    }

    cdq(mid + 1, r);
    return;
}

void solve() {
    cin >> n >> m;
    int sum = 0, j = 0;
    for (int i = 1; i <= n; i++) {
        cin >> arr[i];
        sum += arr[i];
        while (sum > m) {
            sum -= arr[++j];
        }
        b[i] = j;
        dp[i] = INF;
    }
    dp[0] = 0;

    precompute();
    cdq(0, n);
    cout << dp[n] << '\n';
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    solve();
    return 0;
}
```
