# P6514 [QkOI#R1] Quark and Strings

## 题目描述

你需要维护一个字符串序列 $\{S_n\}$，其中有 $n$ 个字符串，初始全为空。接下来有 $q$ 次操作，支持两种操作，下面设当前为第 $i$ 次操作，且本题中字符集为 $[1,q]\cap \N_+$：

- `1 l r`，表示在所有编号在 $[l,r]$ 内的字符串末尾添加字符 $i$，这里 $i$ 是一个 $[1,q]$ 范围内的整数。
- `2 l r`，表示询问所有编号在 $[l,r]$ 内的字符串的最长公共子序列长度。当 $l=r$ 时，我们认为其最长公共子序列长度即为该字符串的长度。

## 输入格式

第一行两个正整数 $n,q$。

接下来 $q$ 行每行三个正整数形如 `1 l r` 或 `2 l r`。

## 输出格式

对于每次操作 $2$，输出一行非负整数作为你的答案。

## 输入输出样例 #1

### 输入 #1

```
5 3
1 1 3
1 1 5
2 1 4

```

### 输出 #1

```
1
```

## 输入输出样例 #2

### 输入 #2

```
8 8
2 8 8
1 3 8
2 5 8
1 1 8
1 1 1
2 3 5
2 1 7
1 2 7
```

### 输出 #2

```
0
1
2
1
```

## 说明/提示

### 样例解释

对于第一组样例：  
第一次操作后，序列为 $\{[1],[1],[1],[],[]\}$。  
第二次操作后，序列为 $\{[1,2],[1,2],[1,2],[2],[2]\}$。  
第三次操作，容易发现询问的最长公共子序列为 $[2]$，长度为 $1$。

---

### 数据范围

**本题采用捆绑测试。**

- Subtask 1（10 pts）：$n,q\le 500$。
- Subtask 2（20 pts）：$n,q\le 1000$。
- Subtask 3（15 pts）：$n\le 1000$，操作 $1$ 不超过 $500$ 次，时限 $2000$ms。
- Subtask 4（15 pts）：$n\le 1000$，操作 $2$ 不超过 $500$ 次，时限 $2000$ms。
- Subtask 5（40 pts）：无特殊限制，时限 $3000$ms。

对于 $100\%$ 的数据，$1\le n,q\le 10^5$，除了特殊标明的 Subtask，其它 Subtask 时限均为 $1000$ms。

### 思路分析

#### 1. 问题转化：LCS 转为三维偏序计数

观察操作 `1 l r` 的性质：每次操作向区间 $[l, r]$ 内所有字符串末尾添加的字符均为**当前操作编号 $i$**（$1 \le i \le q$）。由于 $i$ 随时间严格递增且互不相同，可得出以下两条关键结论：

1. **字符唯一且有序**：对于任意字符串 $S_x$，其中包含的字符两两不同，且严格按照添加时间（即字符数值）递增排列。
2. **公共字符的充要条件**：字符 $c$（由第 $c$ 次操作 `1` 添加，对应区间为 $[L_c, R_c]$）在某次后续询问（第 $t$ 次操作 `2 l r`）时同时存在于 $S_l, S_{l+1}, \dots, S_r$ 中，当且仅当 $c < t$ 且
   $$[l, r] \subseteq [L_c, R_c] \iff L_c \le l \text{ 且 } R_c \ge r$$

由于所有公共字符在每个 $S_x\ (l \le x \le r)$ 中均按严格递增顺序出现，将全部公共字符按升序排成的序列一定是它们的公共子序列；同时，每个字符在单个字符串中至多出现一次，任意公共子序列的长度不可能超过公共字符的总数。因此，最长公共子序列（LCS）的长度就等于公共字符的个数（当 $l = r$ 时，区间 $[l, l]$ 被覆盖的次数即为 $S_l$ 的长度，结论同样成立）。

综上，每次询问 `2 l r`（时间 $t$）等价于统计满足以下三个条件的修改操作 `1 L R`（时间 $t'$）的数量：
1. $t' < t$；
2. $L \le l$；
3. $R \ge r$。

这是一个经典的三维偏序统计问题。

---

#### 2. CDQ 分治与树状数组求解

将所有 $q$ 次操作按时间顺序存入全局数组 `qrys[1..q]`，其中 `type == 2` 的询问操作额外记录询问编号 `id`（从 $1$ 到 `qcnt`）。

对时间区间 $[1, q]$ 进行 CDQ 分治 `cdq(l, r)`：
1. **分治拆解第一维（$t' < t$）**：当 `l >= r` 时直接返回；取 `mid = (l + r) >> 1`，先递归求解 `cdq(l, mid)` 与 `cdq(mid + 1, r)`，再计算左半区间 $[l, mid]$ 的修改对右半区间 $[mid + 1, r]$ 的询问的贡献。此时第一维条件 $t' < t$ 自动满足。
2. **双指针消除第二维（$L \le l$）**：
   - 将左半区间的所有 `type == 1` 修改收集到 `q_1`，将右半区间的所有 `type == 2` 询问收集到 `q_2`；若其中任意一个为空，则当前层无跨中点贡献，直接返回。
   - 借助 `node` 重载的 `<` 运算符，分别对 `q_1` 和 `q_2` 按左端点 `l` 升序排序（左端点相同时按 `r` 升序）。
   - 用指针 `p` 维护 `q_1`，枚举排序后的询问 `pq`：将所有满足 `q_1[p].l <= pq.l` 的修改依次加入数据结构。由于 `pq.l` 单调不减，指针 `p` 只需单向向右推进，无需回退。
3. **树状数组维护第三维（$R \ge r$）**：
   - 使用全局树状数组 `tree`（值域上限 `limit = n`）统计满足 $R \ge r$ 的修改数量。
   - 为将后缀查询转化为前缀和，对右端点坐标作反转映射，令 $\text{pos} = n - R + 1$，则：
     $$R \ge r \iff n - R + 1 \le n - r + 1$$
   - 当指针 `p` 推进时，调用 `add(pos, 1)` 在树状数组对应位置单点加 $1$，并把 `pos` 记录到 `used` 中；随后调用 `query(n - pq.r + 1)` 查询前缀和，累加到对应询问的答案数组 `ans` 中。
4. **回滚状态**：当前层统计结束后，遍历 `used` 执行 `add(e, -1)`，撤销本层对 `tree` 的全部修改，使树状数组恢复全 $0$ 状态而不影响后续分治区间。

### 复杂度分析

- **时间复杂度**：CDQ 分治共有 $O(\log q)$ 层。在每一层中，设当前处理的左右区间总长度为 $m = r - l + 1$，对 `q_1` 和 `q_2` 排序的复杂度为 $O(m \log m)$；双指针扫描时，每个修改至多执行 $1$ 次树状数组插入与 $1$ 次撤销，每个询问至多执行 $1$ 次查询，树状数组单次操作复杂度为 $O(\log n)$，该部分耗时 $O(m \log n)$。由于每层所有区间的长度之和均为 $q$，总时间复杂度为 $O(q \log^2 q + q \log q \log n)$。
- **空间复杂度**：全局数组 `qrys`、`ans` 与树状数组 `tree` 占用 $O(n + q)$ 空间；分治过程中任意时刻沿递归路径上的局部容器 `q_1`、`q_2`、`used` 总长度不超过 $O(q)$。因此总空间复杂度为 $O(n + q)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
constexpr int MAXN = 100005;

int n, q;
int limit;
vector<int> tree;

int lowbit(int x) {
    return x & -x;
}

void add(int x, int val) {
    for (; x <= limit; x += lowbit(x)) {
        tree[x] += val;
    }
    return;
}

int query(int x) {
    int res = 0;
    if (x <= 0) return 0;
    for (; x > 0; x -= lowbit(x)) {
        res += tree[x];
    }
    return res;
}

struct node {
    int l, r, id, type;
    bool operator<(const node& other) const {
        if (l != other.l) return l < other.l;
        else return r < other.r;
    }
} qrys[MAXN];

int ans[MAXN];

void cdq(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    cdq(l, mid);
    cdq(mid + 1, r);

    vector<node> q_1, q_2;
    vector<int> used;
    for (int i = l; i <= mid; i++) {
        if (qrys[i].type == 1) q_1.push_back({qrys[i].l, qrys[i].r, 0});
    }
    for (int i = mid + 1; i <= r; i++) {
        if (qrys[i].type == 2) q_2.push_back({qrys[i].l, qrys[i].r, i});
    }
    if (q_1.empty() || q_2.empty()) return;

    sort(q_1.begin(), q_1.end());
    sort(q_2.begin(), q_2.end());

    int p = 0;
    for (auto pq : q_2) {
        while (p < (int)q_1.size() && q_1[p].l <= pq.l) {
            int pos = n - q_1[p].r + 1;
            add(pos, 1);
            used.push_back(pos);
            p++;
        }
        ans[pq.type] += query(n - pq.r + 1);
    }

    for (auto e : used) {
        add(e, -1);
    }
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> q;
    limit = n;
    tree.assign(n + 5, 0);

    int qcnt = 0;
    for (int i = 1; i <= q; i++) {
        cin >> qrys[i].type >> qrys[i].l >> qrys[i].r;
        if (qrys[i].type == 2) qrys[i].id = ++qcnt;
    }

    cdq(1, q);

    for (int i = 1; i <= qcnt; i++) {
        cout << ans[i] << '\n';
    }
    return 0;
}
```
