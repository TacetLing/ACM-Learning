## 题目描述

有 $n$ 个二元组 $(a_i, b_i)$，编号为 $1$ 到 $n$。

有一个初始为空的栈 $S$，向其中加入元素 $(a_i, b_i)$ 时，先不断弹出栈顶元素直至栈空或栈顶元素 $(a_j , b_j)$ 满足 $a_i \neq a_j$ 且 $b_i < b_j$，然后再将其加入栈中。

如果一个二元组入栈后栈内只有这一个元素，则称该二元组是“成功的”。

有 $q$ 个询问 $[l_i, r_i]$，表示若将编号在 $[l_i, r_i]$ 中的二元组按编号从小到大依次入栈，会有多少个二元组是“成功的”。

询问之间相互独立。

## 输入格式

第一行两个正整数 $n,q$。

第二行 $n$ 个正整数表示 $a_i$。

第三行 $n$ 个正整数表示 $b_i$。

接下来 $q$ 行，每行两个正整数 $l_i, r_i$，表示一组询问。

## 输出格式

$q$ 行，每行一个自然数表示一组询问的答案。

### 思路分析

#### 1. 区间栈状态的等价性转化

记 $S(l, r)$ 为将下标区间 $[l, r]$ 内的二元组按顺序依次入栈后最终得到的栈（元素从栈底到栈顶按入栈顺序排列）。可以证明一个关键性质：对任意 $1 \le l \le r \le n$，$S(l, r)$ 恰好等于 $S(1, r)$ 中所有下标不小于 $l$ 的元素按原相对顺序构成的子序列。

**证明**（固定 $l$，对 $r \ge l$ 进行数学归纳）：
* **基例**：当 $r = l$ 时，$S(l, l) = [l]$。而在 $S(1, l)$ 中，除栈顶元素 $l$ 外其余元素的下标均严格小于 $l$，去掉下标小于 $l$ 的元素后同样为 $[l]$，结论成立。
* **归纳**：假设结论对 $r - 1$ 成立，即 $S(l, r - 1)$ 恰好对应 $S(1, r - 1)$ 中下标不小于 $l$ 的元素。由于入栈元素下标依次增大，栈内元素从栈底到栈顶下标严格递增，因此下标不小于 $l$ 的元素必然连续地位于 $S(1, r - 1)$ 的栈顶一侧。向两栈加入第 $r$ 个元素时，某栈顶元素 $x$ 是否被弹出仅取决于自身与 $r$ 的值（即是否满足 $\text{arr}_x = \text{arr}_r$ 或 $b_x \le b_r$），与栈内更下层的元素无关：
  1. 若 $S(l, r - 1)$ 中的元素全部被 $r$ 弹出，则 $S(1, r - 1)$ 中所有下标 $\ge l$ 的元素也同样会全部被弹出，此后两者中下标 $\ge l$ 的部分均仅剩 $[r]$；
  2. 若在 $S(l, r - 1)$ 中弹栈停留在元素 $x^*$ 处，则在 $S(1, r - 1)$ 中弹栈也必然停留在同一元素 $x^*$ 处，两者中下标 $\ge l$ 的部分依然完全一致。

由归纳原理，该性质对所有 $1 \le l \le r \le n$ 成立。

#### 2. “成功”二元组的充要条件与单调栈预处理

在询问 $[l, r]$ 中，第 $k \in [l, r]$ 个二元组是“成功的”，当且仅当将其入栈后形成的栈 $S(l, k)$ 中仅包含 $k$ 这一个元素。

由上述性质，$S(l, k) = [k]$ 等价于：在 $S(1, k)$ 中，除 $k$ 本身之外，其余所有元素的下标均严格小于 $l$。由于 $S(1, k)$ 从栈底到栈顶的下标严格递增，在 $k$ 下方的所有元素中，下标最大者正是紧邻 $k$ 下方的那个元素。

因此，先对整个序列 $[1, n]$ 模拟一次入栈过程：用栈 `st` 维护当前栈内的元素下标。当第 $i$ 个元素入栈前，不断弹出不满足 `b[st.top()] > b[i]` 且 `arr[st.top()] != arr[i]` 的栈顶元素，随后记录紧邻 $i$ 下方的元素编号：

$$d_i = \begin{cases} \text{栈顶元素下标}, & \text{若 } \text{st} \text{ 非空} \\ 0, & \text{若 } \text{st} \text{ 为空} \end{cases}$$

再将 $i$ 压入 `st`。显然，只要紧邻 $k$ 下方的元素下标 $d_k < l$，其下方所有元素下标就都小于 $l$。于是询问 $[l, r]$ 的答案等价于：

$$\sum_{k=l}^{r} [d_k < l] = \sum_{k=l}^{r} [d_k \le l - 1]$$

#### 3. 主席树维护静态区间值域统计

由于 $d_i \in [0, n]$，上述问题转化为典型的静态区间内小于等于给定值 $l - 1$ 的元素个数查询。可以使用**可持久化权值线段树（主席树）**在值域 $[0, n]$ 上进行维护：

* 全局节点 `tree[0]` 初始为全零空节点，故 `root[0] = 0` 即表示空树，无需显式 `build`。
* 按 $i = 1, 2, \dots, n$ 的顺序，在前一版本 `root[i - 1]` 的基础上调用 `update(root[i], root[i - 1], 0, n, d[i])`，动态开点并令值 $d_i$ 对应的计数加 $1$。
* 对于每次询问 $[l, r]$，利用前缀和差分思想，调用 `query(root[r], root[l - 1], 0, n, l - 1)`，在版本 `root[r]` 与 `root[l - 1]` 上同步统计值域 $[0, l - 1]$ 内的 `sum` 之差即可。若查询过程中出现 `u == v`，说明两版本对应子树完全相同，差值为 $0$，可直接返回剪枝。

### 复杂度分析

* **时间复杂度**：
  * 单调栈预处理过程中，每个下标至多入栈一次、出栈一次，耗时 $O(n)$。
  * 主席树值域长度为 $n + 1$，单次 `update` 耗时 $O(\log n)$，共 $n$ 次更新，建树总耗时 $O(n \log n)$。
  * 每次询问在主席树上统计前缀区间 $[0, l - 1]$，至多访问 $O(\log n)$ 个节点，$q$ 次询问总耗时 $O(q \log n)$。
  * 综合时间复杂度为 $O((n + q)\log n)$。
* **空间复杂度**：
  * 原序列与辅助数组 `arr`、`b`、`d`、`root` 及栈 `st` 占用 $O(n)$ 空间。
  * 主席树树深不超过 $\lceil \log_2(n + 1) \rceil + 1$（当 $n \le 5 \times 10^5$ 时每棵版本至多新增 $20$ 个节点），共 $n$ 次更新，需要 $O(n \log n)$ 的节点空间（对应代码中 `MAXN * 23` 的空间）。
  * 综合空间复杂度为 $O(n \log n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
//#define int long long

constexpr int MAXN = 500005;

struct node {
    int ls, rs, sum;
} tree[MAXN * 23];

int root[MAXN], tot;

void update(int &cur, int prev, int l, int r, int val) {
    cur = ++tot;
    tree[cur] = tree[prev];
    tree[cur].sum++;
    if (l == r) return;
    int mid = (l + r) >> 1;
    if (val <= mid) update(tree[cur].ls, tree[prev].ls, l, mid, val);
    else update(tree[cur].rs, tree[prev].rs, mid + 1, r, val);
    return;
}

int query(int u, int v, int l, int r, int target) {
    if (r <= target) return tree[u].sum - tree[v].sum;
    if (u == v) return 0;
    if (l > target) return 0;
    int mid = (l + r) >> 1;
    return query(tree[u].ls, tree[v].ls, l, mid, target) +
           query(tree[u].rs, tree[v].rs, mid + 1, r, target);
}

int arr[MAXN], b[MAXN], d[MAXN];

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> arr[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    stack<int> st;
    for (int i = 1; i <= n; i++) {
        while (!st.empty() && b[st.top()] <= b[i] || arr[st.top()] == arr[i]) st.pop();
        d[i] = st.empty() ? 0 : st.top();
        st.push(i);
    }

    for (int i = 1; i <= n; i++) {
        update(root[i], root[i - 1], 0, n, d[i]);
    }

    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << query(root[r], root[l - 1], 0, n, l - 1) << '\n';
    }

    return 0;
}
```
