## 题目描述

Bob 有很多迷你手办。他喜欢在电脑屏幕上方的一个架子上展示其中的一些，并且喜欢定期更换展示的手办。这种不断变化的装饰确实令人赏心悦目。Bob 从不重复添加同一个迷你手办。Bob 只有 $N$ 个迷你手办，经过 $N$ 天后，每个手办都被添加过然后又被移除了（因此架子又空了）。

Bob 记忆力非常好。他能记住过去每一天架子上展示了哪些迷你手办。因此，Bob 想做一个小小的脑力练习，来测试自己的记忆力和计算能力。为此，Bob 用数字 $0, \dots, N-1$ 为他的手办编号，并选择一个长度为 $N$ 的整数序列 $d_0 \dots d_{N-1}$，所有整数均在范围 $[0,N]$ 内。然后，Bob 按如下方式计算序列 $x_0,\dots, x_N$：$x_0=0$，$x_{i+1}=(x_i+y_i) \bmod N$，其中 $\bmod$ 是取模运算，$y_i$ 是在第 $d_i$ 天展示的手办中，编号大于或等于 $x_i$ 的手办个数。Bob 的计算结果就是 $x_N$。

更形式化地说，如果我们用 $S(i)$ 表示第 $i$ 天架子上展示的手办对应的 $\{0,\dots,N-1\}$ 的子集，则有：
- $S(0)$ 是空集；
- $S(i)$ 是由 $S(i-1)$ 插入和移除一些元素得到的。
- 每个元素 $0 \le j < N$ 恰好被插入和移除一次，因此，最后一个集合 $S(N)$ 也是空集。

Bob 利用如下程序进行计算。

$$
\begin{array}{l}
x_0 \leftarrow 0 \\
\text{for } i \in [0;N-1] \\
\;\;\;\;\;\;\; x_{i+1} \leftarrow (x_i + \#\{y \in S(d_i) ~\text{ 满足 } ~ y \ge x_i\}) \bmod N \\
\text{output } x_N
\end{array}
$$

Bob 请你验证他的计算。为此，他将他在计算中使用的数字（$d_0, \dots, d_{N-1}$）以及他每天添加或移除了哪些手办的日志交给你。注意，一个在第 $i$ 天添加、第 $j$ 天移除的迷你手办，在满足 $i\leq k < j$ 的第 $k$ 天是存在于架子上的。你应该告诉他你在计算结束时得到的数字。

## 输入格式

输入由 $2N+1$ 行组成。
- 第一行包含整数 $N$。
- 第 $2$ 到第 $N+1$ 行描述了每天添加和移除的手办。
  第 $i+1$ 行包含空格分隔的 $+j$ 或 $-j$，其中 $0 \le j < N$，表示 $j$ 在第 $i$ 天被添加或移除。这一行可能为空。一行中可能同时包含 $+j$ 和 $-j$，按此顺序出现。
- 第 $N+2$ 到第 $2N+1$ 行描述了序列 $d_0,\dots, d_{N-1}$。
  第 $N+2+i$ 行包含整数 $d_i$，满足 $0 \le d_i \le N$。

## 输出格式

输出应包含一行一个整数，即 $x_N$。

## 输入输出样例 #1

### 输入 #1

```
3
+0 +2
-0 +1
-1 -2
1
2
2
```

### 输出 #1

```
2
```

## 说明/提示

输入 #1
```c++
3
+0 +2
-0 +1
-1 -2
1
2
2
```

输出 #1
```c++
2
```

样例解释：  
输出为 $2$，因为
- 首先，$x \leftarrow 2$，因为 $S(1) = \{ 0, 2 \}$ 且 $\#\{y \in S(1) ~\text{满足}~ y \ge 0\} = 2$；
- 然后，$x \leftarrow 0$，因为 $S(2) = \{ 1, 2 \}$ 且 $\#\{y \in S(2) ~\text{满足}~ y \ge 2\} = 1$；
- 最后，$x \leftarrow 2$，因为 $S(2) = \{ 1, 2 \}$ 且 $\#\{y \in S(2) ~\text{满足}~ y \ge 0\} = 2$。

对于所有数据，保证 $N\le 10^5$。

### 思路分析

本题要求维护第 $0$ 天至第 $N$ 天共 $N+1$ 个版本的集合 $S(0), S(1), \dots, S(N)$，并按顺序处理 $N$ 次询问。由于第 $i$ 轮询问更新后的结果 $x_{i+1} = (x_i + y_i) \bmod N$ 直接决定了下一轮查询的阈值，询问具有**强制在线**性质，无法离线重排后统一处理，因此需要利用**可持久化权值线段树（主席树）**显式保存每一天的历史版本。

1. **值域定义与状态维护**
   手办编号范围固定为 $[0, N-1]$。以该区间为值域建立动态开点权值线段树，节点 `tree[cur]` 维护左儿子 `ls`、右儿子 `rs` 以及当前值域区间内的手办总数 `sum`。约定空节点编号为 `0`，其对应的 `sum` 恒为 `0`。

2. **版本继承与单点修改**
   记 `root[i]` 为第 $i$ 天结束时集合 $S(i)$ 对应的线段树根节点，初始空集 $S(0)$ 对应 `root[0] = 0`。对于第 $i$ 天（$1 \le i \le N$）：
   - 先令 `root[i] = root[i - 1]`，继承前一天的集合状态；
   - 随后依次处理当天的每一条操作：若为 `+j`，则对位置 `val` $= j$ 执行增量 `delta` $= +1$ 的修改；若为 `-j`，则执行 `delta` $= -1$ 的修改。

3. **同日多次修改与正确性证明**
   - 代码在单天多次更新时连续调用 `update(root[i], root[i], 0, n - 1, val, delta)`。由于函数第 $1$ 个参数 `cur` 为引用传递，第 $2$ 个参数 `prev` 为值传递，进入 `update` 时 `prev` 已记录修改前的旧版本根编号，随后 `cur = ++tot` 将新分配的节点编号写回 `root[i]` 并复制 `tree[prev]`。因此同一天内的多次操作会在当天最新状态上顺次新建路径节点，既不会破坏历史版本，也不会发生自覆盖冲突。
   - 题目保证每个元素 $j \in [0, N-1]$ 恰好被插入一次、移除一次，且同一天内 `+j` 必然出现在 `-j` 之前（先加后减相互抵消，使 `tree` 中叶节点 `j` 的计数在当天结束时回到 $0$）。由此可知任意版本下每个叶节点的 `sum` 仅可能为 $0$ 或 $1$，不存在负计数或重复计数问题，区间 `sum` 严格等于集合中落在该值域区间内的元素个数。

4. **空行输入解析与在线查询**
   - 题目允许某天没有任何操作（表现为空行），因此不可直接用忽略换行符的 `cin >> op` 读取操作。代码中在读入 `n` 后先用 `getline` 吸收第一行末尾的换行符，随后逐行读取整行字符串 `line`，再通过 `stringstream` 拆分当前行内的所有操作；若为空行，则 `while (ss >> op)` 不执行，`root[i]` 保持与 `root[i - 1]` 一致。
   - 查询阶段只需逐个读入 $d_i$，在版本 `root[d_i]` 中调用 `query(root[d_i], 0, n - 1, x)`，统计值域 $[x, N-1]$ 内的区间和即可得到 $y_i$，随后更新 $x \leftarrow (x + y_i) \bmod N$。

### 复杂度分析

- **时间复杂度**：
  - **建树阶段**：全过程共有 $N$ 个手办，每个手办恰好插入一次、删除一次，因此 `update` 函数的总调用次数严格不超过 $2N$。每次单点修改递归深度为 $O(\log N)$，建树总时间复杂度为 $O(N \log N)$。
  - **查询阶段**：共 $N$ 次询问，每次在线段树上查询后缀区间 $[x, N-1]$。递归过程中若当前区间完全在目标区间左侧（$r < v$）或节点为空则直接返回，若完全被包含（$l \ge v$）则直接返回 `tree[cur].sum`，因此每层至多有 $1$ 个节点继续向下分叉，单次查询访问节点数为 $O(\log N)$，总查询时间复杂度为 $O(N \log N)$。
  - 综上，总时间复杂度为 $O(N \log N)$。

- **空间复杂度**：
  - 值域 $[0, N-1]$（$N \le 10^5$）的动态开点线段树最大深度为 $\lceil \log_2 N \rceil + 1 \le 18$。总计至多 $2N$ 次 `update` 操作，最多新建 $2 \times 10^5 \times 18 = 3.6 \times 10^6$ 个节点（代码中数组开至 `MAXN * 40` 以留足余量）。
  - 版本数组 `root` 占 $O(N)$ 空间，节点数组 `tree` 占 $O(N \log N)$ 空间（约 $48\text{ MB}$），总空间复杂度为 $O(N \log N)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr int MAXN = 100005;

struct node {
    int ls, rs, sum;
} tree[MAXN * 40];

int root[MAXN], tot;

void update(int &cur, int prev, int l, int r, int val, int delta) {
    cur = ++tot;
    tree[cur] = tree[prev];
    tree[cur].sum += delta;
    if (l == r) return;
    int mid = (l + r) >> 1;
    if (val <= mid) update(tree[cur].ls, tree[prev].ls, l, mid, val, delta);
    else update(tree[cur].rs, tree[prev].rs, mid + 1, r, val, delta);
}

int query(int cur, int l, int r, int v) {
    if (cur == 0 || r < v) return 0;
    if (l >= v) return tree[cur].sum;
    int mid = (l + r) >> 1;
    int res = 0;
    if (v <= mid) res += query(tree[cur].ls, l, mid, v);
    res += query(tree[cur].rs, mid + 1, r, v);
    return res;
}

void solve() {
    int n;
    if (!(cin >> n)) return;

    string line;
    getline(cin, line);

    for (int i = 1; i <= n; i++) {
        root[i] = root[i - 1];
        getline(cin, line);
        stringstream ss(line);
        string op;
        while (ss >> op) {
            int val = stoi(op.substr(1));
            int delta = (op[0] == '+') ? 1 : -1;
            update(root[i], root[i], 0, n - 1, val, delta);
        }
    }

    int x = 0;
    for (int i = 0; i < n; i++) {
        int d;
        cin >> d;
        int y = query(root[d], 0, n - 1, x);
        x = (x + y) % n;
    }
    cout << x << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```
