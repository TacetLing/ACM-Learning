# P4755 Beautiful Pair

## 题目描述

小 D 有个数列 $\{a\}$，当一个数对 $(i,j)$（$i \le j$）满足 $a_i$ 和 $a_j$ 的积不大于 $a_i, a_{i+1}, \ldots, a_j$ 中的最大值时，小 D 认为这个数对是美丽的。请你求出美丽的数对的数量。

## 输入格式

第一行输入一个整数 $n$，表示元素个数。
第二行输入 $n$ 个整数 $a_1,a_2,a_3,\ldots,a_n$，为所给的数列。

## 输出格式

输出一个整数，为美丽的数字对数。

## 输入输出样例 #1

### 输入 #1

```
4
1 3 9 3

```

### 输出 #1

```
5

```

## 输入输出样例 #2

### 输入 #2

```
5
1 1 2 1 1

```

### 输出 #2

```
14

```

## 说明/提示

**【样例解释 #1】**

五种可行的数对为 $(1,1), (1,2), (1,3), (1,4), (2,4)$。

**【样例解释 #2】**

只有数对 $(3,3)$ 不可行。

**【数据范围】**

对于 $100 \%$ 的数据，$1\le n\le{10}^5$，$1\le a_i\le{10}^9$。

### 思路分析

#### 用单调栈确定最大值的管辖范围

对于数对 $(p,q)$，选取 $[p,q]$ 内最左边的最大值位置 $i$ 来负责计数。这个约定保证每个数对只在一个位置的枚举中被检查。

固定 $i$，若 $p$ 延伸到左边第一个大于等于 $a_i$ 的位置，就会包含一个更大的值，或者包含一个更靠左的相同最大值。若 $q$ 延伸到右边第一个严格大于 $a_i$ 的位置，区间最大值也会改变。右边与 $a_i$ 相等的元素可以保留，因为 $i$ 仍是最左边的最大值位置。

因此，用单调栈求出以下两个边界：

- `lf[i]` 是左边最近的满足 $a_{\mathrm{lf}[i]}\ge a_i$ 的位置，无此位置时取 $0$。从左往右扫描时，弹出值严格小于 $a_i$ 的栈顶。
- `rg[i]` 是右边最近的满足 $a_{\mathrm{rg}[i]}>a_i$ 的位置，无此位置时取 $n+1$。从右往左扫描时，弹出值小于等于 $a_i$ 的栈顶。

去掉两个边界，令 `L=lf[i]+1`、`R=rg[i]-1`。此时，一个数对由 $i$ 负责计数的充要条件是

$$
L\le p\le i\le q\le R.
$$

#### 枚举短边，用主席树查询另一侧

对于归给 $i$ 的数对，区间最大值已经确定为 $a_i$。固定左端点 $p$ 后，合法条件可以写成

$$
a_p a_q\le a_i
\iff
a_q\le \left\lfloor\frac{a_i}{a_p}\right\rfloor.
$$

因此，只需查询 $[i,R]$ 中有多少个元素不超过 `arr[i]/arr[p]`。固定右端点 $q$ 时同理，在 $[L,i]$ 中查询不超过 `arr[i]/arr[q]` 的元素个数。代码比较 `i-L` 和 `R-i` 来选择较短的一侧。两侧都包含 $i$，因此端点等于 $i$ 的数对也会直接纳入统计，包括 $(i,i)$。

`all_x` 保存排序去重后的原值。主席树建在离散化下标 $[0,\text{sz}-1]$ 上，`root[k]` 记录位置 $1$ 到 $k$ 的元素频数。查询原数组的闭区间 $[l,r]$ 时，使用 `root[r]` 与 `root[l-1]` 的频数之差。

查询时传入的 `target` 是原值上界。对于主席树的一个结点，设它覆盖的离散化下标区间为 $[l,r]$。其原值的最小值和最大值分别为 `all_x[l]` 和 `all_x[r]`：

- 若 `all_x[r]<=target`，整个结点内的值都符合条件，直接返回两个版本的频数之差。
- 若 `all_x[l]>target`，整个结点内的值都超过上界，返回 $0$。
- 其余情况递归查询两个子结点。

每个数对由唯一的最大值位置负责。在该位置的枚举中，短边上的端点只枚举一次，主席树恰好统计长边上满足乘积条件的所有端点。因此，每个合法数对恰好计入一次。

#### 短边枚举的总次数

将整个数组按最左最大值切成左右两段，再分别对两段进行同样的划分。每个分割点 $i$ 对应的待划分区间恰好是单调栈求出的 $[L,R]$。这是因为区间内部满足最左最大值的条件，而区间外紧邻的两个位置若存在，必是先前的分割点。它们的值更大，或与 $a_i$ 相等且在 $i$ 左边，正好构成对应的边界。

固定一个位置 $p$，沿着划分过程观察它所在的区间。每当 $p$ 位于较短的一侧而被枚举，下一步包含它的区间长度就至多是当前区间的一半。区间长度从 $n$ 缩到 $1$，这种枚举对同一个位置最多发生 $O(\log n)$ 次。再加上 $p$ 本身作为最大值时的一次枚举，所有位置总共贡献 $O(n\log n)$ 次查询。

### 复杂度分析

- **时间复杂度。** 两遍单调栈共耗时 $O(n)$，离散化和建立主席树共耗时 $O(n\log n)$。每次查询统计一个值域前缀，每层至多有一个结点需要继续向下划分，因此单次查询耗时 $O(\log n)$。总计 $O(n\log n)$ 次查询，总时间复杂度为 $O(n\log^2 n)$。
- **空间复杂度。** 每次插入复制 $O(\log n)$ 个结点，主席树占用 $O(n\log n)$ 空间。其余数组和单调栈占用 $O(n)$ 空间，总空间复杂度为 $O(n\log n)$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
//#define int long long
constexpr int MAXN=100005;
int arr[MAXN];
struct node{
    int ls,rs,sum;
}tree[MAXN*23];
int root[MAXN],tot;
vector<int> all_x;

void update(int &cur,int prev,int l,int r,int val){
    cur=++tot;
    tree[cur]=tree[prev];
    tree[cur].sum++;
    if(l==r) return;
    int mid=(l+r)>>1;
    if(val<=mid) update(tree[cur].ls,tree[prev].ls,l,mid,val);
    else update(tree[cur].rs,tree[prev].rs,mid+1,r,val);
    return;
}

int query(int u,int v,int l,int r,int val){
    if(all_x[r]<=val) return tree[u].sum-tree[v].sum;
    if(all_x[l]>val) return 0;
    int mid=(l+r)>>1;
    int res=0;
    res+=query(tree[u].ls,tree[v].ls,l,mid,val)+query(tree[u].rs,tree[v].rs,mid+1,r,val);
    return res;
}

int n;
stack<int> st;
int lf[MAXN],rg[MAXN];

int get_idx(int x){
    return lower_bound(all_x.begin(),all_x.end(),x)-all_x.begin();
}

void solve(){
    cin>>n;
    for(int i=1;i<=n;i++) cin>>arr[i],all_x.push_back(arr[i]);
    sort(all_x.begin(),all_x.end());
    all_x.erase(unique(all_x.begin(),all_x.end()),all_x.end());

    for(int i=1;i<=n;i++){
        while(!st.empty() && arr[st.top()]<arr[i]){
            st.pop();
        }
        if(st.empty()) lf[i]=0;
        else lf[i]=st.top();
        st.push(i);
    }

    while(!st.empty()) st.pop();
    for(int i=n;i>=1;i--){
        while(!st.empty() && arr[st.top()]<=arr[i]){
            st.pop();
        }
        if(st.empty()) rg[i]=n+1;
        else rg[i]=st.top();
        st.push(i);
    }

    int sz=all_x.size();
    for(int i=1;i<=n;i++){
        update(root[i],root[i-1],0,sz-1,get_idx(arr[i]));
    }

    long long ans=0;
    for(int i=1;i<=n;i++){
        int L=lf[i]+1,R=rg[i]-1;
        if(i-L<=R-i){
            for(int j=L;j<=i;j++){
                int target=arr[i]/arr[j];
                ans+=query(root[R],root[i-1],0,sz-1,target);
            }
        }
        else{
            for(int j=i;j<=R;j++){
                int target=arr[i]/arr[j];
                ans+=query(root[i],root[L-1],0,sz-1,target);
            }
        }
    }

    cout<<ans<<'\n';
    return;
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    solve();
    return 0;
}
```
