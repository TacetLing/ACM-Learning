# P5838 [USACO19DEC] Milk Visits G

## 题目描述

Farmer John 计划建造 $N$ 个农场，用 $N-1$ 条道路连接，构成一棵树（也就是说，所有农场之间都互相可以到达，并且没有环）。每个农场有一头奶牛，品种为 $1$ 到 $N$ 之间的一个整数 $T_i$。

Farmer John 的 $M$ 个朋友经常前来拜访他。在朋友 $i$ 拜访之时，Farmer John 会与他的朋友沿着从农场 $A_i$ 到农场 $B_i$ 之间的唯一路径行走（可能有 $A_i = B_i$）。除此之外，他们还可以品尝他们经过的路径上任意一头奶牛的牛奶。由于 Farmer John 的朋友们大多数也是农场主，他们对牛奶有着极强的偏好。他的每个朋友都只喝某种特定品种的奶牛的牛奶。任何 Farmer John 的朋友只有在他们访问时能喝到他们偏好的牛奶才会高兴。

请求出每个朋友在拜访过后是否会高兴。

## 输入格式

输入的第一行包含两个整数 $N$ 和 $M$。

第二行包含 $N$ 个空格分隔的整数 $T_1,T_2,\ldots, T_N$。第 $i$ 个农场内的奶牛的品种用 $T_i$ 表示。

以下 $N-1$ 行，每行包含两个不同的整数 $X$ 和 $Y$（$1 \leq X, Y \leq N$），表示农场 $X$ 与 $Y$ 之间有一条边。

以下 $M$ 行，每行包含整数 $A_i$，$B_i$，以及 $C_i$。$A_i$ 和 $B_i$ 表示朋友 $i$ 拜访时行走的路径的端点，$C_i$（$1\le C_i\le N$）表示这个朋友喜欢的牛奶的奶牛品种。

## 输出格式

输出一个长为 $M$ 的二进制字符串。如果第 $i$ 个朋友会感到高兴，则字符串的第 $i$ 个字符为 `1`，否则为 `0`。

### 思路分析

本题要求判断树上任意两点 $A_i$ 与 $B_i$ 之间的唯一路径上是否存在权值恰好为 $C_i$ 的节点。由于树上路径在原编号下不具备连续区间性质，难以直接进行区间统计；因此考虑先通过**树链剖分**将树上路径拆分为若干段下标连续的重链区间，再配合**可持久化线段树（主席树）**完成各段区间内的单点频次查询。

1. **树链剖分与连续 DFS 序构造**
   - 第一遍遍历 `dfs_1` 计算每个节点的深度 `dep`、父节点 `fa`、子树大小 `sz` 以及重儿子 `son`（子树 `sz` 最大的子节点）。
   - 第二遍遍历 `dfs_2` 优先递归访问重儿子 `son[u]`，再依次访问其余轻儿子，同时记录每个节点的 DFS 序 `dfn[u]`、逆映射 `rev[cnt] = u` 以及所在重链的链顶 `top[u]`：沿重边向下时继承原链顶 $t$，跨过轻边进入子节点 $v$ 时则以 $v$ 自身作为新重链的链顶。
   - **关键性质**：由于 `dfs_2` 总是优先遍历重儿子，同一条重链上的所有节点在 `dfn` 序中必然严格连续递增；此外，任意节点到根节点路径上的轻边数量不超过 $\lfloor \log_2 N \rfloor$ 条，故树上任意一条路径 $(u, v)$ 均可被剖分为至多 $O(\log N)$ 段连续的 `dfn` 区间。

2. **基于 `dfn` 序构建主席树**
   - 题中所有奶牛品种 $T_i$ 与询问偏好 $C_i$ 均满足 $1 \le T_i, C_i \le N$，可直接以 $[1, N]$ 作为权值线段树的值域，无需离散化。
   - 按 DFS 序 $i = 1, 2, \dots, N$ 的顺序，将对应节点 `rev[i]` 的权值 `arr[rev[i]]` 通过 `update` 插入权值线段树，在上一版本 `root[i - 1]` 的基础上动态开点生成新版本 `root[i]`。
   - 由此，版本 `root[i]` 维护了 `dfn` 序前 $i$ 个节点中各品种的出现次数。对于任意闭区间 $[L, R]$，利用前缀作差原理，版本 `root[R]` 与 `root[L - 1]` 在叶节点 `target` 处 `sum` 值的差，即为该区间内品种 `target` 的出现次数。在 `query` 中，若当前值域区间总数差 $\text{tree}[u].\text{sum} - \text{tree}[v].\text{sum} = 0$，说明该值域内无任何目标区间元素，可直接剪枝返回 $0$。

3. **路径跳链查询与正确性证明（`check` 函数）**
   - **异链跳转**：当 $\text{top}[u] \ne \text{top}[v]$ 时，说明 $u, v$ 尚不在同一条重链上。通过比较链顶深度 $\text{dep}[\text{top}[u]]$ 与 $\text{dep}[\text{top}[v]]$，保证让链顶深度较大的一端（不妨设为 $u$）向上跳转。
     - **正确性说明**：若仅比较节点自身深度 $\text{dep}[u]$ 与 $\text{dep}[v]$，节点较深的一侧其链顶可能位于最近公共祖先 $\text{LCA}(u, v)$ 的上方，整段跳转会越过 $\text{LCA}$ 导致错误；而链顶深度更大的一侧，其链顶 $\text{top}[u]$ 必然严格处于 $\text{LCA}(u, v)$ 的下方（或处于不同分支），故重链区间 $[\text{dfn}[\text{top}[u]], \text{dfn}[u]]$ 必完全包含于路径 $(u, v)$ 之中，且跳转至 `fa[top[u]]` 绝不会越过 $\text{LCA}$。
     - 调用 `query(root[dfn[u]], root[dfn[top[u]] - 1], 1, n, c)` 查询闭区间 $[\text{dfn}[\text{top}[u]], \text{dfn}[u]]$ 内品种 $c$ 的数量。若大于 $0$ 则表明路径上已存在目标品种，立即返回 `true`；否则令 `u = fa[top[u]]` 继续向上合并路径。
   - **同链收尾**：当循环终止时必有 $\text{top}[u] = \text{top}[v]$，即 $u, v$ 已位于同一条重链上（其中深度较浅者即为 $\text{LCA}(u, v)$）。调整使 $\text{dep}[u] \le \text{dep}[v]$ 后，查询最后一段闭区间 $[\text{dfn}[u], \text{dfn}[v]]$，即 `query(root[dfn[v]], root[dfn[u] - 1], 1, n, c)`。若结果大于 $0$ 返回 `true`，全部区段均未找到则返回 `false`。

### 复杂度分析

- **时间复杂度**：
  - 树链剖分两遍 DFS 遍历整棵树，耗时 $O(N)$。
  - 按 `dfn` 序依次建立主席树共进行 $N$ 次单点更新，值域为 $[1, N]$，单次更新递归深度为 $O(\log N)$，建树总耗时 $O(N \log N)$。
  - 单次询问通过 `check` 最多拆分为 $O(\log N)$ 段重链区间，每段区间在主席树上进行一次单点查询耗时 $O(\log N)$，因此单次询问最坏时间复杂度为 $O(\log^2 N)$，$M$ 次询问总耗时 $O(M \log^2 N)$。
  - 综上所述，总体时间复杂度为 $O(N \log N + M \log^2 N)$。

- **空间复杂度**：
  - 邻接表 `adj` 及树链剖分辅助数组占用空间 $O(N)$。
  - 主席树共有 $N$ 个历史版本，每次 `update` 最多新建 $\lceil \log_2 N \rceil + 1$ 个节点，故空间复杂度为 $O(N \log N)$（在 $N = 10^5$ 下至多约 $1.8 \times 10^6$ 个节点，数组大小开至 `MAXN * 23` 满足要求）。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr int MAXN = 100005;

struct node {
    int ls, rs, sum;
} tree[MAXN * 23];

int root[MAXN], tot;

void update(int &cur, int prev, int l, int r, int val) {
    cur = ++tot;
    tree[cur] = tree[prev];
    tree[cur].sum++;
    if (l == r) return;
    int mid = (l + r) >> 1;
    if (val <= mid) update(tree[cur].ls, tree[prev].ls, l, mid, val);
    else update(tree[cur].rs, tree[prev].rs, mid + 1, r, val);
}

int query(int u, int v, int l, int r, int target) {
    if (tree[u].sum - tree[v].sum == 0) return 0;
    if (l == r) return tree[u].sum - tree[v].sum;
    int mid = (l + r) >> 1;
    if (target <= mid) return query(tree[u].ls, tree[v].ls, l, mid, target);
    else return query(tree[u].rs, tree[v].rs, mid + 1, r, target);
}

vector<int> adj[MAXN];
int dfn[MAXN], dep[MAXN], fa[MAXN], son[MAXN], top[MAXN], rev[MAXN], sz[MAXN], cnt;

void dfs_1(int u, int f, int d) {
    dep[u] = d;
    fa[u] = f;
    sz[u] = 1;
    int max_sz = -1;
    for (auto v : adj[u]) {
        if (v == f) continue;
        dfs_1(v, u, d + 1);
        sz[u] += sz[v];
        if (sz[v] > max_sz) {
            max_sz = sz[v];
            son[u] = v;
        }
    }
}

void dfs_2(int u, int t) {
    top[u] = t;
    dfn[u] = ++cnt;
    rev[cnt] = u;
    if (!son[u]) return;
    dfs_2(son[u], t);
    for (auto v : adj[u]) {
        if (v == fa[u] || v == son[u]) continue;
        dfs_2(v, v);
    }
}

int n, m;
int arr[MAXN];

bool check(int u, int v, int c) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        if (query(root[dfn[u]], root[dfn[top[u]] - 1], 1, n, c) > 0) return true;
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    if (query(root[dfn[v]], root[dfn[u] - 1], 1, n, c) > 0) return true;
    return false;
}

void solve() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> arr[i];
    }
    for (int i = 1; i <= n - 1; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    dfs_1(1, 0, 0);
    dfs_2(1, 1);
    for (int i = 1; i <= n; i++) {
        update(root[i], root[i - 1], 1, n, arr[rev[i]]);
    }
    for (int i = 1; i <= m; i++) {
        int a, b, c;
        cin >> a >> b >> c;
        cout << (check(a, b, c) ? '1' : '0');
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```
