# P16844 [GKS 2021 #B] Truck Delivery

## 题目描述

Charles 是 Googleland 城市的一名卡车司机。Googleland 的结构是一棵有 $N$ 个节点的树，每个节点代表一个城市，每条边代表两个城市之间的道路。城市编号为 $1$ 到 $N$。Googleland 的首都是城市 $1$。每天，Charles 在城市 $C$ 装载重量为 $W$ 的货物，并希望沿城市间的唯一简单路径将货物运送到城市 $1$。每条道路 $i$ 设有一个通行费，如果货物重量大于或等于载重限制 $L_i$，则需支付金额 $A_i$。

Charles 工作 $Q$ 天，每天给出起点城市 $C$ 和货物重量 $W$。对于每天，求 Charles 当天支付的所有通行费的最大公约数。如果当天无需支付任何通行费，则答案为 $0$。

## 输入格式

输入的第一行给出测试用例的数量 $T$。接下来有 $T$ 个测试用例。

每个测试用例的第一行包含两个整数 $N$ 和 $Q$。

接下来的 $N-1$ 行描述道路。其中第 $i$ 行包含四个空格分隔的整数 $X$、$Y$、$L_i$ 和 $A_i$，表示连接城市 $X$ 和 $Y$ 的道路，其载重限制为 $L_i$，通行费为 $A_i$。

接下来的 $Q$ 行描述查询。其中第 $j$ 行包含两个空格分隔的整数 $C_j$ 和 $W_j$，表示第 $j$ 天的起点城市和货物重量。

## 输出格式

对于每个测试用例，输出一行，格式为 `Case #x: y`，其中 $x$ 是测试用例编号（从 $1$ 开始），$y$ 是按顺序给出的 $Q$ 天答案列表，用空格分隔。

### 思路分析

本题给定一棵以 $1$ 号节点为根的树，要求多次询问从节点 $c$ 到根 $1$ 的路径上所有满足 $l \le w$ 的边权 $a$ 的最大公约数。由于查询仅涉及“点到根”的固定前缀路径，可利用**边权转点权**与**树上主席树**直接支持在线查询。

1. **边权转点权**
   以 $1$ 为根时，树上除根节点外的每个节点 $u$ 均有唯一的父节点 `fa` 及对应的父边。将每条边上的限制 `l` 与通行费 `a` 下放到子节点身上，则“从 $c$ 到根 $1$ 的路径上的边”等价于“路径上除 $1$ 之外的所有节点”。

2. **树上主席树建模与版本继承**
   - 以道路载重限制 `l` 为值域下标建立动态开点权值线段树，值域为 $[1, \text{MAXL}]$（其中 $\text{MAXL} = 2 \times 10^5$）。节点 `tree[cur]` 维护左儿子 `ls`、右儿子 `rs` 以及当前值域区间内所有通行费的最大公约数 `g`。约定空节点编号为 `0`，其对应的 `g` 恒为 `0`。
   - 记 `root[u]` 为从根 $1$ 到节点 $u$ 的路径上所有边构成的权值线段树根节点，根节点空路径对应 `root[1] = 0`。
   - 从 $1$ 号节点执行一次 `dfs(u, fa)`：对于 $u$ 的每个子节点 `e.to`，令版本 `root[e.to]` 直接在父版本 `root[u]` 的基础上调用 `update(root[e.to], root[u], 1, MAXL, e.l, e.a)`，将下标 `e.l` 处的叶节点赋值为 `e.a`，并在回溯过程中通过 `get_gcd(tree[ls].g, tree[rs].g)` 向上合并区间 $\gcd$。

3. **正确性证明**
   - 题目保证所有边的限制 $L_i$ 互不相同，因此从根 $1$ 到任意节点 $u$ 的路径上不会出现相同的 `e.l`，`update` 到达叶节点时直接覆盖赋值 `tree[cur].g = val` 即可，不会发生权值冲突。
   - 空节点与未填入边权的叶子默认值为 `0`。由 $\gcd(x, 0) = x$ 与 $\gcd(0, 0) = 0$ 可知，`0` 天然充当了 $\gcd$ 运算的单位元：既不影响已有边权的公约数合并，也能保证当路径上不存在任何满足 $l \le w$ 的边时，区间查询结果自动返回 `0`，与题目规定完全一致。

4. **在线查询与多组数据复用**
   - 对于每次询问 $(c, w)$，直接在版本 `root[c]` 上调用 `query(root[c], 1, MAXL, w)`，统计值域前缀 $[1, w]$ 的区间 $\gcd$ 即为当天答案。
   - 多组测试数据开始时，仅需重置 `tot = 0`、`root[1] = 0` 并清空邻接表 `adj`。无需 `memset` 清空整个 `tree` 数组，因为每次 `update` 新建节点都会通过 `tree[cur] = tree[prev]` 完整覆写旧数据，而 `tree[0]` 始终未被修改，恒为全零状态。

### 复杂度分析

- **时间复杂度**：
  - 记值域上限为 $L = \text{MAXL} = 2 \times 10^5$，权值上限为 $V = \max A_i \le 10^{18}$。
  - 每次 `update` 和 `query` 访问的线段树节点数均为 $O(\log L)$；若每次合并 `get_gcd` 均按最坏 $O(\log V)$ 估算，单次操作粗略上界为 $O(\log L \log V)$。
  - 进一步利用辗转相除法的势能伸缩分析：对于非零正整数 $x, y$，设 $g = \gcd(x, y)$，一次 `get_gcd(x, y)` 的取模次数不超过 $1 + 2\log_2\frac{x}{g}$。无论是在 `update` 中由叶向根合并，还是在 `query` 中自左向右合并各子区间，当前维护的 $\gcd$ 值均单调不增，相邻层之间的对数差值互相抵消，因此单次 `update` 与单次 `query` 的紧确时间复杂度均为 $O(\log L + \log V)$。
  - 单组数据的建树与查询总时间复杂度为 $O((N + Q)(\log L + \log V))$（粗略上界为 $O((N + Q)\log L \log V)$）。

- **空间复杂度**：
  - 值域 $[1, 2 \times 10^5]$ 的动态开点线段树最大深度为 $\lceil \log_2(2 \times 10^5) \rceil + 1 = 19$。每组数据有 $N - 1$ 条边，新建节点数至多为 $5 \times 10^4 \times 19 = 9.5 \times 10^5$ 个，代码中开设 `MAXN * 22`（约 $1.1 \times 10^6$ 个 `Node`）余量充足。
  - 所有测试数据共用同一静态节点池 `tree`（约占 $17.6\text{ MB}$），加上邻接表 `adj` 与 `root` 数组的 $O(N)$ 开销，总空间复杂度为 $O(N \log L)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr int MAXN = 50005;
constexpr int MAXL = 200000;

struct Node {
    int ls, rs;
    long long g;
} tree[MAXN * 22];

struct Edge {
    int to, l;
    long long a;
};

vector<Edge> adj[MAXN];
int root[MAXN], tot;

long long get_gcd(long long a, long long b) {
    return b ? get_gcd(b, a % b) : a;
}

void update(int &cur, int prev, int l, int r, int pos, long long val) {
    cur = ++tot;
    tree[cur] = tree[prev];
    if (l == r) {
        tree[cur].g = val;
        return;
    }
    int mid = (l + r) >> 1;
    if (pos <= mid) update(tree[cur].ls, tree[prev].ls, l, mid, pos, val);
    else update(tree[cur].rs, tree[prev].rs, mid + 1, r, pos, val);
    tree[cur].g = get_gcd(tree[tree[cur].ls].g, tree[tree[cur].rs].g);
}

long long query(int cur, int l, int r, int R) {
    if (cur == 0 || l > R) return 0;
    if (r <= R) return tree[cur].g;
    int mid = (l + r) >> 1;
    long long res = query(tree[cur].ls, l, mid, R);
    if (R > mid) res = get_gcd(res, query(tree[cur].rs, mid + 1, r, R));
    return res;
}

void dfs(int u, int fa) {
    for (const auto &e : adj[u]) {
        if (e.to == fa) continue;
        update(root[e.to], root[u], 1, MAXL, e.l, e.a);
        dfs(e.to, u);
    }
}

void solve(int tc) {
    int n, q;
    cin >> n >> q;

    tot = 0;
    root[1] = 0;
    for (int i = 1; i <= n; i++) adj[i].clear();

    for (int i = 1; i < n; i++) {
        int u, v, l;
        long long a;
        cin >> u >> v >> l >> a;
        adj[u].push_back({v, l, a});
        adj[v].push_back({u, l, a});
    }

    dfs(1, 0);

    cout << "Case #" << tc << ":";
    while (q--) {
        int c, w;
        cin >> c >> w;
        cout << " " << query(root[c], 1, MAXL, w);
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    if (cin >> T) {
        for (int tc = 1; tc <= T; tc++) {
            solve(tc);
        }
    }
    return 0;
}
```
