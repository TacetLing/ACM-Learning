这是该问题的困难版本。本版本与其他版本的区别在于，所有测试用例中 $r - l + 1$ 之和没有任何限制。

你有一个变量 $x$，初始值为 $0$。每次操作，你可以选择以下两种操作中的一种：

- 操作 $1$：将 $2^k$ 加到 $x$，其中 $k$ 为在此之前连续执行操作 $1$ 的次数（特别地，如果这是第一次操作或上一次操作为操作 $2$，则 $k=0$）；
- 操作 $2$：将 $x$ 减去 $1$（结果可以为负数）。

对于非负整数 $n$，记 $f(n)$ 为使 $x$ 恰好等于 $n$ 所需的最少操作次数。你可以证明这总是可行的。

现在给定两个整数 $l$ 和 $r$，请计算 $\sum\limits_{n = l}^{r} f(n)$。由于答案可能非常大，请对 $998\,244\,353$ 取模后输出。

## 输入格式

每个测试点包含多个测试用例。第一行包含测试用例个数 $t$ （$1 \le t \le 10^4$）。接下来的每个测试用例包含一行，含两个整数 $l$ 和 $r$（$0 \le l \le r \le 10^{18}$）。

## 输出格式

对于每个测试用例，输出一行一个整数，即 $\sum\limits_{n = l}^{r} f(n)$ 对 $998\,244\,353$ 取模后的结果。

## 说明/提示

在第一个测试用例中，$l = r = 4$。初始状态 $x = 0$。一种可以达到最优的 6 步操作序列如下：

1. 执行操作 $1$，此时 $k = 0$，所以 $x$ 变为 $0 + 2^0 = 1$。
2. 再次执行操作 $1$，此时 $k = 1$，$x$ 变为 $1 + 2^1 = 3$。
3. 再次执行操作 $1$，此时 $k = 2$，$x$ 变为 $3 + 2^2 = 7$。
4. 执行操作 $2$，$x$ 变为 $7 - 1 = 6$。
5. 再次执行操作 $2$，$x$ 变为 $6 - 1 = 5$。
6. 再次执行操作 $2$，$x$ 变为 $5 - 1 = 4$。

可以证明无法用 $5$ 步或更少的操作让 $x = 4$，所以 $f(4) = 6$，故答案为 $6$。

在第二个测试用例中，$l = 1$，$r = 3$，有 $f(1) = 1$、$f(2) = 3$、$f(3) = 2$，所以答案为 $1 + 3 + 2 = 6$。

在第三个测试用例中，$l = r = 127$，连续执行 $7$ 次操作 $1$ 可以使 $x = 2^7 - 1 = 127$。可以证明无法用 $6$ 步或更少的操作得到 $x = 127$，所以 $f(127) = 7$，答案为 $7$。

### 思路分析

#### 将操作序列转化为连续段

设操作 1 的连续段长度依次为 $a_1,\ldots,a_m$，操作 2 共执行 $d$ 次。对于 $n\ge 1$，至少需要一段操作 1。长度为 $a_i$ 的一段使 $x$ 增加 $2^{a_i}-1$，因此要恰好得到 $n$，必须有

$$
d=\sum_{i=1}^{m}(2^{a_i}-1)-n.
$$

相邻两段之间至少需要一次操作 2，所以 $d\ge m-1$。反过来，只要 $d\ge m-1$，就可以在每对相邻段之间各执行一次操作 2，再把剩余的操作 2 放在最后。因此，这组连续段可行的充要条件为

$$
\sum_{i=1}^{m}(2^{a_i}-2)\ge n-1.
$$

令 $g(n)=f(n)+n$。对于一组可行的连续段，将总操作次数加上 $n$，得到

$$
\sum_{i=1}^{m}a_i+d+n
=\sum_{i=1}^{m}(2^{a_i}+a_i-1).
$$

所以 `get_g(n)` 求的是满足可行条件时，上式的最小值。随着 $n$ 增大，可行条件逐渐收紧，而同一组连续段的代价固定，因此 $g(n)$ 单调不减。

#### 推导 `get_g` 的递推式

当 $n\ge 2$ 时，长度为 $1$ 的段对可行条件的贡献为 $0$，可以删去。若有两段长度同为 $a\ge2$，可以合并为一段长度为 $a+1$ 的段。合并后，对可行条件的贡献增加 $2$，代价减少 $a-2$。每次合并都会减少段数，因此总能得到一个段长互异的最优方案。

对于 $n\ge4$，令 $k=\lfloor\log_2 n\rfloor$，$b=2^k$，即代码中的 `base`。此时 $b\le n\le 2b-1$。所有小于 $k$ 的不同段长，其贡献之和小于 $b-1\le n-1$，所以最优方案至少包含一段长度不小于 $k$ 的段。

- 若方案中存在长度至少为 $k+1$ 的段，单独取一段长度为 $k+1$ 的段即可满足条件，且其代价至多等于原方案中该段的代价。对应 `opt1`，代价为 $2b+k$。
- 若方案的最大段长为 $k$，取出这一段后，剩余部分需要提供至少 $n-1-(b-2)$ 的贡献，对应目标 $n-b+2$。反过来，将长度为 $k$ 的段加入目标 $n-b+2$ 的最优方案，就能满足原目标的可行条件。对应 `opt2`，代价为 $b+k-1+g(n-b+2)$。

因此

$$
g(n)=\min\bigl(2b+k,\ b+k-1+g(n-b+2)\bigr).
$$

初值为 $g(0)=0$、$g(1)=2$、$g(2)=g(3)=5$。其中 $n=1$ 只需执行一次操作 1，$n=2,3$ 均可用一段长度为 $2$ 的连续段达到，且长度为 $2$ 的段是能提供正贡献的最低代价选择。`memo` 记录已经求出的 $g(n)$。

#### 二分分界点并计算前缀和

`S(n)` 表示 $\sum_{i=0}^{n}g(i)$ 对模数取模的结果。对于当前块 $[b,2b-1]$，先递归求出前面各块的和 `S(base-1)`，再处理当前块内的 $[b,n]$。

`opt2` 的代价不超过 `opt1` 当且仅当

$$
g(i-b+2)\le b+1.
$$

由 $g$ 的单调性，满足条件的 $i$ 构成 $[b,n]$ 的一个前缀。代码用二分求出这个前缀的右端点 `split_p`，记为 $p$。初始令 $p=b-1$，用来表示前缀为空。

在 $[b,p]$ 上使用 `opt2`。其中常数项 $b+k-1$ 出现 $p-b+1$ 次，递归项的下标从 $2$ 到 $p-b+2$，其和为 $S(p-b+2)-S(1)$。在 $[p+1,n]$ 上使用 `opt1`，每一项均为 $2b+k$。因此，把三部分加起来并取模即可得到

$$
S(n)\equiv S(b-1)
+(p-b+1)(b+k-1)
+S(p-b+2)-S(1)
+(n-p)(2b+k)
\pmod{998244353}.
$$

`memo_s` 记录已经求出的前缀和。最后，由 $f(n)=g(n)-n$，所求答案为

$$
S(r)-S(l-1)-\frac{(r-l+1)(l+r)}{2}
\pmod{998244353}.
$$

当 $l=0$ 时，代码将 $S(l-1)$ 按 $0$ 处理。`sum_n` 用 $2$ 的模逆元 `INV2` 计算等差数列的和。

### 复杂度分析

设 $B$ 为输入上界的二进制位数，本题中 $B\le60$。

- **时间复杂度。** `get_g` 每层只有一个递归分支，至多连续两层处于同一二进制块，因此单次求值最多访问 $O(B)$ 个状态。每个新 `S` 状态进行 $O(B)$ 次二分判定。所有 `S(base-1)` 调用只有 $O(B)$ 个不同参数，而每个 `S` 状态的另一条递归分支 `S(split_p-base+2)` 会进入更低的二进制块。这是因为 $g(b)>b+1$，通过判定的下标最大为 $b-1$。从 $O(t)$ 个查询端点和 $O(B)$ 个块前缀端点出发，至多产生 $O((t+B)B)$ 个 `S` 状态。计入 `map` 的查找和插入，令 $D=(t+B)B^3$，总时间复杂度上界为 $O(D\log(D+1))$。
- **空间复杂度。** 两个 `map` 至多保存 $O(D)$ 个状态，递归栈占用 $O(B)$ 空间，总空间复杂度上界为 $O(D)$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MOD=998244353;
constexpr int INV2=499122177;
map<int,int> memo;
map<int,int> memo_s;

int get_g(int n){
    if(n==0) return 0;
    if(n==1) return 2;
    if(n==2) return 5;
    if(n==3) return 5;
    if(memo[n]!=0) return memo[n];

    int k=63-__builtin_clzll(n);
    int opt1=(1ULL<<(k+1))+k;
    int opt2=(1LL<<k)+k-1+get_g(n-(1LL<<k)+2);
    int ans=min(opt1,opt2);
    memo[n]=ans;
    return ans;
}

int S(int n){
    if(n==0) return 0;
    if(n==1) return 2;
    if(n==2) return 7;
    if(n==3) return 12;
    if(memo_s.count(n)) return memo_s[n];

    int k=63-__builtin_clzll(n);
    int base=1LL<<k;
    int ans=S(base-1);
    int l=base,r=(k==62 ? n : min(n,(base<<1)-1)),split_p=base-1;
    while(l<=r){
        int mid=(l+r)>>1;
        if(get_g(mid-base+2)<=base+1){
            split_p=mid;
            l=mid+1;
        }
        else{
            r=mid-1;
        }
    }

    if(split_p>=base){
        int cnt=(split_p-base+1)%MOD;
        int c=((base%MOD)+k-1)%MOD;
        ans=(ans+cnt*c)%MOD;
        ans=(ans+S(split_p-base+2)-S(1)+MOD)%MOD;
    }
    if(n>split_p){
        int cnt=(n-split_p)%MOD;
        int opt1_c=((1ULL<<(k+1))%MOD+k)%MOD;
        ans=(ans+cnt*opt1_c)%MOD;
    }
    return memo_s[n]=ans;
}

int sum_n(int l,int r){
    int len=(r-l+1)%MOD;
    int sum=((l%MOD)+(r%MOD))%MOD;
    return (len*sum%MOD)*INV2%MOD;
}

void solve(){
    int l,r;
    cin>>l>>r;
    int sum_g=(S(r)-(l==0 ? 0 : S(l-1))+MOD)%MOD;
    int sub=sum_n(l,r);
    int ans=(sum_g-sub+MOD)%MOD;
    cout<<ans<<'\n';
    return;
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    int t;
    cin>>t;
    while(t--) solve();
    return 0;
}
```
