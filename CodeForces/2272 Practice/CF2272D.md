# CF2272D Connecting the Conflicts

## 题目描述

A tree is a connected graph without cycles. Define an [independent set](https://en.wikipedia.org/wiki/Independent_set_(graph_theory)) of a tree as a set of vertices such that no two distinct vertices in the set are directly connected by an edge in the tree. A maximum independent set is an independent set that contains the largest possible number of vertices.

Given a forest of  $ k $  trees, we want to add  $ k-1 $  edges to unite the forest into a single tree so as to maximize the size of the maximum independent set of the resulting tree. Please find the additional edges.

If there are several valid answers, you may output any of them.

## 输入格式

Each test contains multiple test cases. The first line contains the number of test cases  $ t $  ( $ 1 \le t \le 10^4 $ ). The description of the test cases follows.

The first line of each test case contains a single integer  $ k $  ( $ 2 \le k \le 2 \cdot 10^5 $ ) — the number of trees in the forest.

This is followed by a description of each of the  $ k $  trees, which are numbered  $ 1, 2, \ldots, k $  in order:

The first line contains a single integer  $ n $  ( $ 1\le n \le 2 \cdot 10^5 $ ) — the size of the tree. The vertices of the tree are numbered with integers from  $ 1 $  to  $ n $ .

Each of the next  $ n-1 $  lines contains two integers  $ u $  and  $ v $  ( $ 1 \le u,v \le n $ ,  $ u \ne v $ ), denoting an edge between vertices  $ u $  and  $ v $ . It is guaranteed that the given edges form a tree.

It is guaranteed that the sum of  $ k $  over all test cases does not exceed  $ 2 \cdot 10^5 $ .

It is guaranteed that the sum of  $ n $  over all test cases does not exceed  $ 2 \cdot 10^5 $ .

## 输出格式

For each test case, output  $ k-1 $  lines; each line contains four integers  $ t_1, v_1, t_2, v_2 $ , denoting an edge between  $ (t_1,v_1) $  and  $ (t_2,v_2) $  that is added to the original graph.

Note that we number all  $ k $  trees from  $ 1 $  to  $ k $  in the order in which they appear in the input data. For any tree  $ i $  ( $ 1\le i \le k $ ), if it contains  $ n $  nodes, then its nodes are numbered from  $ 1 $  to  $ n $ . The  $ j $ -th node in this tree is denoted by  $ (i,j) $ .

## 输入输出样例 #1

### 输入 #1

```
2
2
1
1
2
3
1 2
1 3
1
```

### 输出 #1

```
2 1 1 1
2 1 1 1
```

## 说明/提示

In the first test case, the graph has two vertices and no edge; adding an edge between these two nodes is the only way to turn the graph into a tree.

In the second test case, we can add an edge between the only vertex  $ 1 $  of tree  $ 2 $  and one of the vertices  $ 1 $ ,  $ 2 $ , and  $ 3 $  of tree  $ 1 $ .

- add edge  $ (2,1)-(1,1) $ , the size of a maximum independent set of the resulting tree is 3.
- add edge  $ (2,1)-(1,2) $ , the size of a maximum independent set of the resulting tree is 2.
- add edge  $ (2,1)-(1,3) $ , the size of a maximum independent set of the resulting tree is 2.

So, we choose the edge  $ (2,1)-(1,1) $  since it is optimal.


### 思路分析

#### 1. 问题转化与理论上界
设第 $i$ 棵树 $T_i$ 的最大独立集大小为 $\alpha(T_i)$。通过添加 $k - 1$ 条边将 $k$ 棵树合并为一棵大树 $T$ 后，原森林中的所有边依然保留在 $T$ 中。对于 $T$ 的任意独立集 $I$，其在每棵原树 $T_i$ 上的子集 $I \cap V(T_i)$ 必然也是 $T_i$ 的合法独立集，因此合并后的最大独立集大小存在理论上界：
$$\alpha(T) \le \sum_{i=1}^k \alpha(T_i)$$
解题的核心在于构造一种加边方案，使最终的大树能够取到尽可能大的独立集（即尽可能达到上述上界）。

#### 2. 树形 DP 与“白点” $\text{white}[i]$ 的求法
对于每棵大小为 $n$ 的树（固定以节点 $1$ 为根），利用树形 DP 求解其最大独立集。设 $\text{dp}[u][0]$ 与 $\text{dp}[u][1]$ 分别表示在以 $u$ 为根的子树中，**不选节点 $u$** 与 **选中节点 $u$** 时子树内最大独立集的大小：
- **初始状态**：仅考虑节点 $u$ 本身时，不选贡献为 $0$，选中贡献为 $1$，即 $\text{dp}[u][0] = 0$，$\text{dp}[u][1] = 1$。
- **状态转移**：遍历 $u$ 的所有子节点 $v$：
  - 若不选 $u$，则子节点 $v$ 选或不选均可，故 $\text{dp}[u][0] \mathrel{+}= \max(\text{dp}[v][0], \text{dp}[v][1])$；
  - 若选中 $u$，则子节点 $v$ 一定不能选，故 $\text{dp}[u][1] \mathrel{+}= \text{dp}[v][0]$。
整棵树的最大独立集大小为 $\alpha(T_i) = \max(\text{dp}[1][0], \text{dp}[1][1])$。

若某节点在**至少一种**大小等于 $\alpha(T_i)$ 的最大独立集中未被选中，则称该节点为树 $T_i$ 的“白点”，用 $\text{white}[i]$ 记录：
- **当 $n = 1$ 时**：树仅包含孤立点 $1$，最大独立集必须选中节点 $1$，不存在白点，代码中暂令 $\text{white}[i] = 1$。
- **当 $n \ge 2$ 时**：树至少包含一条边，而独立集不可能同时包含一条边的两个端点，因此树上必定存在白点。跑完 $\text{dfs}(1, 0)$ 后可以直接确定一个白点：
  - 若 $\text{dp}[1][0] \ge \text{dp}[1][1]$，说明存在不选根节点 $1$ 即可取得最大独立集的方案，因此根节点 $1$ 本身就是白点，令 $\text{white}[i] = 1$；
  - 若 $\text{dp}[1][1] > \text{dp}[1][0]$，说明任意最大独立集都必须选中根节点 $1$，此时节点 $1$ 的所有邻居均不能被选中；由于 $n \ge 2$，节点 $1$ 至少存在一个邻接点 $\text{adj}[1][0]$，令 $\text{white}[i] = \text{adj}[1][0]$ 必然是一个合法白点。

#### 3. 合并构造与正确性证明
代码中用变量 $p$ 记录最后一棵点数 $n \ge 2$ 的树（若所有树都满足 $n = 1$，则保留初值 $p = 1$）。构造方案为：对于所有 $i \ne p$，添加一条连接 $(i, \text{white}[i])$ 与 $(p, \text{white}[p])$ 的边。分两种情况证明其最优性：

- **情况 1：所有树都满足 $n = 1$**。
  此时森林退化为 $k$ 个孤立点，连接成的任意 $k$ 个节点的树均至少有一条边，最大独立集大小至多为 $k - 1$。此时 $p = 1$ 且所有 $\text{white}[i] = 1$，方案将 $(2, 1), (3, 1), \dots, (k, 1)$ 全部连向 $(1, 1)$ 构成菊花图；除中心 $(1, 1)$ 外其余 $k - 1$ 个点互不相邻，构成大小为 $k - 1$ 的独立集，达到最优。
- **情况 2：存在至少一棵点数 $n \ge 2$ 的树**。
  此时 $p$ 必对应一棵点数 $\ge 2$ 的树，且 $(p, \text{white}[p])$ 是树 $T_p$ 在某个最大独立集 $I_p$ 中**未被选中**的白点。对于其余每棵树 $T_i$（$i \ne p$），任取其各自的一个最大独立集 $I_i$，构造集合：
  $$I = I_p \cup \bigcup_{i \ne p} I_i$$
  其大小恰好等于理论上界 $\sum_{i=1}^k \alpha(T_i)$。考察新增的 $k - 1$ 条边：每条边都以 $(p, \text{white}[p])$ 为其中一个端点，而 $(p, \text{white}[p]) \notin I_p$，即该端点不在 $I$ 中。因此，没有任何一条新增边的两端点同时属于 $I$，$I$ 依然是合并后整棵树的合法独立集，从而严格取到理论最大值。

每棵树处理完毕后调用 $\text{init}(n)$ 清空 `dp` 与 `adj`，以便下一棵树复用全局数组。

### 复杂度分析

- **时间复杂度**：对第 $i$ 棵树建图、执行 $\text{dfs}(1, 0)$ 与 $\text{init}(n)$ 的时间均为 $O(n_i)$；最后输出 $k - 1$ 条边耗时 $O(k)$。因此单组测试数据时间复杂度为 $O\left(k + \sum_{i=1}^k n_i\right)$，所有测试数据总时间复杂度为 $O(\sum k + \sum n)$。
- **空间复杂度**：全局数组 `adj`、`dp`、`white` 大小均为 $\text{MAXN}$，单棵树处理完即清空复用；$\text{dfs}$ 递归栈深度不超过单棵树的大小 $n_i$，总空间复杂度为 $O(\max k + \max n)$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MAXN = 200005;

vector<int> adj[MAXN];
int dp[MAXN][2];
int white[MAXN];

void dfs(int u, int f) {
    for (auto v : adj[u]) {
        if (v == f) continue;
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
    return;
}

void init(int sz) {
    for (int i = 1; i <= sz; i++) {
        dp[i][0] = dp[i][1] = 0;
        adj[i].clear();
    }
    return;
}

int k, n;

void solve() {
    cin >> k;
    int p = 1;
    for (int i = 1; i <= k; i++) {
        cin >> n;
        for (int j = 1; j <= n - 1; j++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
            adj[v].push_back(u);
        }
        if (n == 1) white[i] = 1;
        else {
            p = i;
            dfs(1, 0);
            if (dp[1][0] >= dp[1][1]) white[i] = 1;
            else white[i] = adj[1][0];
        }
        init(n);
    }

    for (int i = 1; i <= k; i++) {
        if (i == p) continue;
        cout << i << ' ' << white[i] << ' ' << p << ' ' << white[p] << '\n';
    }
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```
