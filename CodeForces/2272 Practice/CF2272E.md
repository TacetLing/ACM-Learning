# CF2272E Memory Cell Interception

## 题目描述

有两个线程 $\texttt{A}$ 和 $\texttt{B}$，以及一个共享内存单元。初始时，该单元中存储的值为 $0$。

线程 $\texttt{A}$ 有一个长度为 $n$ 的固定指令序列 $s$，线程 $\texttt{B}$ 有一个长度为 $m$ 的固定指令序列 $t$。每条指令要么是读指令 $\texttt{READ}$，记作 $\texttt{R}$，要么是写指令 $\texttt{WRITE}$，记作 $\texttt{W}$。

每个线程中的指令都必须按原顺序执行，但来自两个线程的指令可以任意交错执行。换句话说，实际执行的全局指令序列由 $s$ 和 $t$ 合并而成，包含 $n+m$ 条指令，且两个序列各自的指令顺序保持不变。

例如，设 $s=$ $\texttt{RWW}$，$t=$ $\texttt{WR}$。

- 序列 $s_1,t_1,s_2,t_2,s_3$ 是一种合法的交错顺序，对应的全局指令序列为 $\texttt{RWWRW}$。
- 序列 $s_2,t_1,s_1,t_2,s_3$ 不是合法的交错顺序，因为 $s$ 中的指令没有按原顺序执行。
- 序列 $s_1,t_1,s_2,t_2$ 不是合法的交错顺序，因为它没有执行所有指令。

全局执行过程使用时间戳。在执行任何指令之前，时间戳为 $0$。全局序列中第 $i$ 条指令的执行时间戳为 $i$。

- 在时间戳 $i$ 执行 $\texttt{WRITE}$ 指令时，将值 $i$ 写入共享内存单元。
- 执行 $\texttt{READ}$ 指令时，读取共享内存单元中当前存储的时间戳值。

对于 $s$ 和 $t$ 中的每一条 $\texttt{READ}$ 指令，求在两个指令序列的所有合法交错顺序中，该指令可以读到多少种不同的值。

## 输入格式

每个测试点包含多组测试数据。第一行包含测试用例数 $t$（$1 \le t \le 10^4$）。接下来依次给出各组测试数据。

每组测试数据的第一行包含两个整数 $n$ 和 $m$（$1 \le n,m \le 2 \cdot 10^5$），分别表示线程 $\texttt{A}$ 和 $\texttt{B}$ 的指令序列长度。

第二行包含一个长度为 $n$ 的字符串 $s$，表示线程 $\texttt{A}$ 的指令序列。

第三行包含一个长度为 $m$ 的字符串 $t$，表示线程 $\texttt{B}$ 的指令序列。

$s$ 和 $t$ 中的每个字符都是 $\texttt{R}$ 或 $\texttt{W}$，且两个字符串各自至少包含一个字符 $\texttt{R}$。

保证所有测试用例的 $n$ 之和不超过 $2 \cdot 10^5$，$m$ 之和也不超过 $2 \cdot 10^5$。

## 输出格式

对于每组测试数据，输出两行。

第一行输出一个整数序列，依次表示 $s$ 中每条 $\texttt{READ}$ 指令的答案。该序列的长度必须等于 $s$ 中字符 $\texttt{R}$ 的数量。

第二行输出一个整数序列，依次表示 $t$ 中每条 $\texttt{READ}$ 指令的答案。该序列的长度必须等于 $t$ 中字符 $\texttt{R}$ 的数量。

### 思路分析

#### 1. 问题转化
根据题意，每次执行 $\texttt{READ}$（记作 $\texttt{R}$）指令时，读取到的值等于全局执行序列中**位于该指令之前的最后一次 $\texttt{WRITE}$（记作 $\texttt{W}$）指令的时间戳**；若其前方不存在任何 $\texttt{W}$ 指令，则读到初始值 $0$。

由于两个线程 $s_1$ 和 $s_2$ 完全对称，我们可以抽象出辅助函数 `work(B, b, pre_B, A, a, q)`，用于依次计算线程 $B$（长度为 $b$）中每条 $\texttt{R}$ 指令的答案，而将另一线程 $A$（长度为 $a$）视为交错来源。代码中在字符串首部拼接空格将其转为 $1$-indexed，并预处理 `pre_1` 和 `pre_2`，其中 `pre_B[i]` 表示 $B[1 \dots i]$ 中最后一条 $\texttt{W}$ 的位置（不存在则为 $0$），参数 $q$ 表示 $A$ 中最后一条 $\texttt{W}$ 的位置（即 `pre_A[a]`，若 $A$ 中无 $\texttt{W}$ 则 $q = 0$）。在 `solve()` 中分别对 `s1` 和 `s2` 调用一次 `work` 即可。

---

#### 2. 分类讨论

考察 $B$ 中位置 $x$ 上的读指令（$B[x] = \texttt{R}$，$1 \le x \le b$），记 `p = pre_B[x - 1]`，即 $B[x]$ 之前同一线程内最后一条 $\texttt{W}$ 的位置。

##### 情况一：$p \neq 0$（$B[x]$ 前方存在同线程的 $\texttt{W}$）
1. **下界分析**：由于 $B[1 \dots p]$ 均必须在 $B[p]$ 之前或之时执行，因此 $B[p]$ 的时间戳至少为 $p$；又因为 $B[p]$ 必在 $B[x]$ 之前执行，故 $B[x]$ 读到的值不小于 $p$。
2. **上界分析**：
   - 若 $q = 0$（$A$ 中不含 $\texttt{W}$）：$B[x]$ 之前的最后一次写只能是 $B[p]$。至多将 $A[1 \dots a]$ 全部置于 $B[p]$ 之前，而 $B[p+1 \dots x-1]$ 这 $x - 1 - p$ 条 $\texttt{R}$ 必须位于 $B[p]$ 与 $B[x]$ 之间，故 $B[p]$ 的时间戳至多为 $a + p$。
   - 若 $q \neq 0$（$A$ 中含有 $\texttt{W}$）：$B[x]$ 之前的最后一次写要么是 $B[p]$（最大时间戳为 $a + p$），要么是 $A$ 中的某条 $\texttt{W}$。将 $A[q+1 \dots a]$ 全部置于 $B[x]$ 之后，并将 $B[1 \dots x-1]$ 全部置于 $A[q]$ 之前，可使 $A[q]$ 达到最大时间戳 $q + x - 1$。因此上界为 $\max(a + p,\; q + x - 1)$。
3. **区间连续性证明**：
   - 保持 $B[1 \dots x-1]$ 连续，将 $A$ 的前 $0, 1, \dots, a$ 条指令置于 $B[1 \dots p]$ 之前（其余 $A$ 的指令置于 $B[x]$ 之后），此时 $B[p]$ 作为最后一次写，其时间戳恰好取遍 $[p,\; a + p]$ 内的所有整数。
   - 当 $q \neq 0$ 时，仅保留 $A[1 \dots q]$ 在 $B[x]$ 之前，将 $A[1 \dots q-1]$、$B[1 \dots p]$ 以及 $B[p+1 \dots x-1]$ 中的前 $t$ 条（$0 \le t \le x - 1 - p$）置于 $A[q]$ 之前，其余置于 $A[q]$ 与 $B[x]$ 之间，此时 $A[q]$ 作为最后一次写，其时间戳恰好取遍 $[q + p,\; q + x - 1]$。
   - 因为 $q \le a$，必有 $q + p \le a + p$，两段区间必定相交或衔接，中间没有空洞。
4. **答案公式**：
   - 若 $q = 0$：可达区间为 $[p,\; a + p]$，答案为 $a + 1$。
   - 若 $q \neq 0$：可达区间为 $[p,\; \max(a + p,\; q + x - 1)]$，答案为
     $$\max(a + p,\; q + x - 1) - p + 1 = \max(a + 1,\; q + x - p)$$

##### 情况二：$p = 0$（$B[x]$ 前方不存在同线程的 $\texttt{W}$）
此时 $B[1 \dots x-1]$ 全部为 $\texttt{R}$。
1. **可达值集合**：
   - 若不将 $A$ 的任何 $\texttt{W}$ 置于 $B[x]$ 之前，则读到初始值 $0$，故 $0$ 恒可达。
   - 若令 $A$ 中位置 $j$ 的 $\texttt{W}$ 作为 $B[x]$ 之前的最后一次写，可将 $A[j+1 \dots a]$ 全部置于 $B[x]$ 之后，并在 $A[j]$ 之前插入 $B[1 \dots x-1]$ 中的任意 $0 \sim x-1$ 条 $\texttt{R}$（剩余留于 $A[j]$ 与 $B[x]$ 之间）。由此，每个 $A[j] = \texttt{W}$ 均贡献连续区间 $[j,\; j + x - 1]$。
   - 可达值集合为：
     $$\{0\} \cup \bigcup_{A[j] = \texttt{W}} [j,\; j + x - 1]$$
2. **集合大小推导**：
   - 若 $q = 0$（$A$ 中无 $\texttt{W}$），集合仅为 $\{0\}$，答案为 $1$。
   - 若 $q \neq 0$，设 $A$ 中所有 $\texttt{W}$ 的位置依次为 $j_1 < j_2 < \dots < j_c$（$c \ge 1$），相邻间距为 $d_i = j_i - j_{i-1}$（$2 \le i \le c$）。
   - 由于 $j_1 \ge 1$，$0$ 与所有区间均不相交，贡献 $1$；第一个区间 $[j_1,\; j_1 + x - 1]$ 贡献 $x$；按左端点递增依次加入第 $i$ 个区间 $[j_i,\; j_i + x - 1]$ 时，此前已覆盖的最右端为 $j_{i-1} + x - 1$，因此第 $i$ 个区间新增覆盖的元素个数为 $\min(x,\; d_i)$。总集合大小为：
     $$1 + x + \sum_{i=2}^{c} \min(x,\; d_i)$$
3. **预处理加速**：
   为避免对每个 $x$ 暴力求和，利用双计数思想将求和式按值域拆解为：
   $$\sum_{i=2}^{c} \min(x,\; d_i) = \sum_{i=2}^{c} \sum_{k=1}^{x} [d_i \ge k] = \sum_{k=1}^{x} \sum_{i=2}^{c} [d_i \ge k]$$
   在 `work` 中，先利用 `cnt[d]` 统计各间距 $d_i$（$1 \le d_i < a$）的出现次数；再从 $a$ 到 $1$ 逆序求后缀和，使 `suf[k]` 表示满足 $d_i \ge k$ 的间距数量；最后求 `suf` 的前缀和 `f[k]` $= \sum_{t=1}^{k} \text{suf}_t$（代码数组 `suf[t]`）。由于所有间距均满足 $d_i < a$，当 $x > a$ 时 $\min(x,\; d_i) = d_i$ 保持不变，直接查询 `f[min(x, a)]` 即可，从而在 $O(1)$ 时间内得到情况二答案 `1 + x + f[min(x, a)]`。

---

### 复杂度分析

- **时间复杂度**：预处理 `pre_1` 和 `pre_2` 耗时 $O(n + m)$；每次调用 `work` 时，局部清空 `0` 到 `a + 1`、统计间距、计算前后缀和以及扫描求解总耗时为 $O(a + b)$。单组测试数据时间复杂度为 $O(n + m)$，全部测试数据总时间复杂度为 $O(\sum n + \sum m)$。
- **空间复杂度**：使用了长度为 `MAXN` 的全局数组 `pre_1`、`pre_2`、`cnt`、`suf`、`f` 以及输入字符串 `s1`、`s2`，空间复杂度为 $O(n + m)$（静态数组上界为 $O(\max(n, m))$）。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MAXN = 200005;

string s1, s2;
int pre_1[MAXN], pre_2[MAXN];
int cnt[MAXN], suf[MAXN], f[MAXN];
int n, m;

void work(const string& B, int b, const int pre_B[], const string& A, int a, int q) {
    for (int i = 0; i <= a + 1; i++) {
        cnt[i] = suf[i] = f[i] = 0;
    }

    int last_w = 0;
    for (int i = 1; i <= a; i++) {
        if (A[i] == 'W') {
            if (last_w != 0) {
                cnt[i - last_w]++;
            }
            last_w = i;
        }
    }

    for (int k = a; k >= 1; k--) {
        suf[k] = suf[k + 1] + cnt[k];
    }
    for (int k = 1; k <= a; k++) {
        f[k] = f[k - 1] + suf[k];
    }

    for (int x = 1; x <= b; x++) {
        if (B[x] == 'R') {
            int p = pre_B[x - 1];
            int ans;
            if (p != 0) {
                ans = (q == 0 ? a + 1 : max(a + 1, q + x - p));
            } else {
                ans = (q == 0 ? 1 : 1 + x + f[min(x, a)]);
            }
            cout << ans << ' ';
        }
    }
    cout << '\n';
}

void solve() {
    cin >> n >> m >> s1 >> s2;
    s1 = ' ' + s1;
    s2 = ' ' + s2;
    for (int i = 1; i <= n; i++) {
        if (s1[i] == 'W') pre_1[i] = i;
        else pre_1[i] = pre_1[i - 1];
    }
    for (int i = 1; i <= m; i++) {
        if (s2[i] == 'W') pre_2[i] = i;
        else pre_2[i] = pre_2[i - 1];
    }

    work(s1, n, pre_1, s2, m, pre_2[m]);
    work(s2, m, pre_2, s1, n, pre_1[n]);
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
