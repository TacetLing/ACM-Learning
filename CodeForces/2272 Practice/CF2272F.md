# CF2272F Tree Reduction Game

## 题目描述

Alice 和 Bob 在一棵有 $ n $ 个顶点的树上玩游戏。Alice 先手，之后两人轮流操作。

游戏中的任何时刻，树都有一个指定的根。设当前的根为 $ u $。轮到一名玩家时，该玩家必须选择 $ u $ 的一个子节点 $ v $，并执行以下两种操作之一：

1. 将 $ v $ 设为新的根。
2. 删除以 $ v $ 为根的整棵子树 $ ^{\text{∗}} $。

父子关系以当前的根为准。

在整个游戏过程中，每个顶点最多只能成为根一次。

如果一名玩家在自己的回合中没有合法操作，则该玩家输掉游戏。

游戏开始前，作为后手的补偿，Bob 可以选择任意一个顶点作为初始根。

给定这棵树，假设两名玩家都采用最优策略，请判断谁会获胜。如果 Bob 能获胜，请按顶点编号从小到大的顺序输出所有能使他保证获胜的初始根。

$ ^{\text{∗}} $ 以顶点 $ v $ 为根的子树由所有到当前根的简单路径经过 $ v $ 的顶点组成（包括 $ v $ 本身）。

## 输入格式

输入包含多组测试数据。第一行包含一个整数 $ t $（$ 1 \le t \le 10^4 $），表示测试数据的组数。接下来依次描述每组测试数据。

每组测试数据的第一行包含一个整数 $ n $（$ 2 \le n \le 5 \cdot 10^5 $），表示树的顶点数。

接下来的 $ n-1 $ 行，每行包含两个整数 $ u $ 和 $ v $（$ 1 \le u,v \le n $，$ u \ne v $），表示顶点 $ u $ 与 $ v $ 之间有一条边。保证给出的图是一棵树。

保证所有测试数据的 $ n $ 之和不超过 $ 5 \cdot 10^5 $。

## 输出格式

- 如果 Alice 获胜，输出 `Alice`。
- 否则，第一行输出 `Bob`。第二行输出一个整数 $ k $，表示 Bob 选作初始根后能保证获胜的顶点个数。第三行按升序输出 $ k $ 个互不相同的整数 $ v_1,v_2,\ldots,v_k $，表示所有这样的顶点。

如果 Bob 选择顶点 $ 2 $ 作为初始根，那么它的子节点是 $ 1 $ 和 $ 3 $。

- 如果 Alice 将根从 $ 2 $ 改为 $ 1 $，Bob 可以将根从 $ 1 $ 改为 $ 4 $（或 $ 6 $）。
- 如果 Alice 删除以 $ 1 $ 为根的子树，Bob 就删除以 $ 3 $ 为根的子树，使 Alice 无法进行合法操作。
- 如果 Alice 将根从 $ 2 $ 改为 $ 3 $，Bob 就删除以 $ 2 $ 为根的子树，同样使 Alice 无法进行合法操作。
- 如果 Alice 删除以 $ 3 $ 为根的子树，Bob 就删除以 $ 1 $ 为根的子树。

### 思路分析

#### 1. 游戏状态的等价化简
题目规定“每个顶点最多只能成为根一次”。假设某一时刻玩家执行**操作 1**，将当前根从 $p$ 移动至子节点 $u$：
* 由于树中任意两点间的简单路径唯一，任何试图进入 $p$ 所在子树内部顶点的移动都必须先经过 $p$。而 $p$ 已经当过根，后续无法再被选为新根，因此双方再也不可能将根移入 $p$ 这一侧的分支。
* 这意味着对于当前根 $u$ 而言，曾经当过根的邻接分支（称为**旧分支**）无论原本规模多大，后续唯一合法的操作只剩“用**操作 2**将其整棵删去”；而其余从未当过根的邻接子节点，其内部尚未被访问或局部删除，仍保持完整子树形态。

因此，游戏任意时刻的局面仅由以下两部分唯一决定：
1. 当前根 $u$ 挂载的若干棵未访问子树 $T_{v_1}, T_{v_2}, \dots, T_{v_m}$；
2. 布尔标记 $b \in \{0, 1\}$：表示当前根是否仍挂有一个只能执行操作 2 删除的旧分支（游戏开始时 $b = 0$；一旦通过操作 1 移向某个未访问子节点 $v$，新局面必定满足 $b = 1$）。

#### 2. 博弈胜负态判定
定义子树状态 $f(T_u) \in \{0, 1\}$ 表示：当某一方通过操作 1 将根移入 $u$ 后，对手面对“以 $u$ 为根、包含 $m$ 个未访问子节点且带有旧分支（$b = 1$）”的局面时，该行动方（即对手）是否必胜（$1$ 表示必胜，$0$ 表示必败）。

现考察处于根 $u$（含 $m$ 个未访问子节点与旧分支标记 $b \in \{0, 1\}$）的当前行动方：
* **情形一：存在至少一个未访问子节点 $v_i$ 满足 $f(T_{v_i}) = 0$**
  当前行动方只需直接执行操作 1 将根移至 $v_i$，即可迫使对手进入必败局面（$b = 1$ 且 $f(T_{v_i}) = 0$）。故此时无论 $b = 0$ 还是 $b = 1$，当前行动方均**必胜**。
* **情形二：所有未访问子节点均满足 $f(T_{v_i}) = 1$**
  若对任意 $v_i$ 执行操作 1，对手均会立即进入必胜态，因此双方都不会主动执行操作 1，只能轮流使用操作 2 逐个删除这 $m$ 个子节点或旧分支（总计 $m + b$ 个可删分支）。每次删除仅使剩余可删分支数减 $1$，且其余子节点依然全为 $f = 1$，直至可删分支数为 $0$ 时当前行动方无合法操作而判负。由奇偶归纳可知，当前行动方必胜当且仅当 $m + b$ 为奇数。

分别代入 $b = 1$ 与 $b = 0$，可得两条精确判定条件：
1. **子树 $f$ 值转移（$b = 1$）**：
   $$f(T_u) = \begin{cases} 0, & \text{若所有子节点均满足 } f(T_{v_i}) = 1 \text{ 且 } m \equiv 1 \pmod 2 \\ 1, & \text{其他情况} \end{cases}$$
2. **初始根必胜条件（$b = 0$，Alice 先手）**：
   选定初始根 $r$ 时无旧分支（$b = 0$），Alice 必败（即 Bob 必胜）当且仅当：
   * $r$ 的所有邻接分支均满足 $f = 1$；
   * $r$ 的度数 $\deg(r)$ 为偶数（此时 $m + 0$ 为偶数）。

#### 3. 换根 DP 实现
采用两遍 DFS 在线性时间内求得所有满足条件的初始根：
1. **第一遍 DFS（`dfs_1`）**：任选 $1$ 号点为根，自底向上统计每个节点 `u` 的子节点中满足 `f[v] == 0` 的个数 `cnt[u]` 以及子节点总数 `child_cnt`，由上述公式求得 `f[u]`。
2. **第二遍 DFS（`dfs_2`）**：从根 $1$ 出发向下换根，参数 `up_f` 表示当前以 `u` 为全树之根时，原父节点 `fa` 一侧整块分支的 $f$ 值（`u == 1` 时无父侧分支）。
   * 汇总 `u` 的所有邻接分支中 $f = 0$ 的总数 `total_zero`：在 `cnt[u]` 的基础上，若 `u != 1` 且 `up_f == 0`，则额外加 $1$。若满足 `total_zero == 0` 且 `adj[u].size()` 为偶数，则标记 `win[u] = true`。
   * 向子节点 `v` 换根时，将 `v` 这一支从 `u` 的邻接分支中剥离：剩余子节点数为 `mv = adj[u].size() - 1`，剩余分支中 $f = 0$ 的个数为 `zv = total_zero - (f[v] == 0 ? 1 : 0)`。直接套用同一判定公式算得 `u` 一侧对于 `v` 的状态 `nxt_up_f`，向下递归 `dfs_2(v, u, nxt_up_f)`。
3. 最后按编号 $1 \sim n$ 升序收集所有 `win[i] == true` 的节点输出即可。

### 复杂度分析

* **时间复杂度**：每组测试数据中，建图、第一遍 DFS（`dfs_1`）、第二遍换根 DFS（`dfs_2`）及按序收集答案均只遍历每个顶点与每条边常数次，单组时间复杂度为 $O(n)$；所有测试数据总时间复杂度为 $O(\sum n)$。
* **空间复杂度**：邻接表 `adj` 与辅助数组 `f`、`cnt`、`win` 均为线性大小，递归栈最大深度为 $O(n)$，空间复杂度为 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MAXN = 500005;

vector<int> adj[MAXN];
int f[MAXN], cnt[MAXN];
bool win[MAXN];
int n, t;

void dfs_1(int u, int fa) {
    cnt[u] = 0;
    int child_cnt = 0;
    for (auto v : adj[u]) {
        if (v == fa) continue;
        child_cnt++;
        dfs_1(v, u);
        if (f[v] == 0) cnt[u]++;
    }
    f[u] = (cnt[u] == 0 && child_cnt % 2 == 1) ? 0 : 1;
}

void dfs_2(int u, int fa, int up_f) {
    int total_zero = cnt[u];
    if (u != 1 && up_f == 0) total_zero++;
    if (total_zero == 0 && adj[u].size() % 2 == 0) {
        win[u] = true;
    }
    int mv = adj[u].size() - 1;
    for (auto v : adj[u]) {
        if (v == fa) continue;
        int zv = total_zero - (f[v] == 0 ? 1 : 0);
        int nxt_up_f = (zv == 0 && mv % 2 == 1) ? 0 : 1;
        dfs_2(v, u, nxt_up_f);
    }
    return;
}

void solve() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        adj[i].clear();
        win[i] = false;
    }
    for (int i = 1; i <= n - 1; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    dfs_1(1, 0);
    dfs_2(1, 0, 1);

    vector<int> ans;
    for (int i = 1; i <= n; i++) {
        if (win[i]) ans.push_back(i);
    }
    if (ans.empty()) {
        cout << "Alice\n";
    } else {
        cout << "Bob\n";
        cout << ans.size() << "\n";
        for (int i = 0; i < (int)ans.size(); i++) {
            cout << ans[i] << (i + 1 == (int)ans.size() ? '\n' : ' ');
        }
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> t;
    while (t--) solve();
    return 0;
}
```
