# CF2272C Yet Another Black Cell Problem

## 题目描述

Inspired by [this problem](https://codeforces.com/contest/2026/problem/B).

There is a strip divided into cells numbered from  $ 0 $  to  $ 10^9 $  from left to right. Initially, all cells are white.

An array  $ a $  of length  $ n $  is given, containing the indices of  $ n $  cells. We want to paint all these  $ n $  cells black.

Given an integer  $ x $ , you may choose an integer  $ y $  such that  $ 0 \le y \le x $ , and then arbitrarily select  $ y $  cells that are not in  $ a $ . We also want to paint these selected  $ y $  cells black while keeping all non-selected cells white.

You may perform the following operation any number of times:

- Choose two distinct cells  $ i $  and  $ j $  such that  $ 1 \le |i-j| \le k $ , and paint them black, regardless of whether they were originally black or white.

Find the minimum value of  $ k $  for which it is possible to paint all the required cells black while keeping other cells white.

## 输入格式

Each test contains multiple test cases. The first line contains the number of test cases  $ t $  ( $ 1 \le t \le 10^4 $ ). The description of the test cases follows.

The first line of each test case contains two integers  $ n $  and  $ x $  ( $ 2\leq n\leq 2\cdot 10^5,0\leq x\leq n $ ).

The second line contains  $ n $  integers  $ a_1,a_2,\ldots,a_n $  ( $ 0\leq a_i\leq 10^{9} $ ). It is guaranteed that  $ a_i \lt a_{i+1} $  for all  $ 1 \leq i  \lt  n $ .

It is guaranteed that the sum of  $ n $  over all test cases does not exceed  $ 2\cdot 10^5 $ .

## 输出格式

For each test case, print a single integer — the minimum value of  $ k $  for which it is possible to paint all the required cells black while keeping other cells white.

## 输入输出样例 #1

### 输入 #1

```
4
2 0
1 3
2 1
1 3
3 1
2 5 7
10 2
0 6 8 10 13 14 16 19 25 31
```

### 输出 #1

```
2
1
2
3
```

## 说明/提示

In the first example, we cannot paint any cell other than  $ 1 $  and  $ 3 $  black because  $ x=0 $ . So it's optimal to set  $ k=2 $  and choose  $ i=1,j=3 $  in the first operation.

In the second example, we can set  $ k=1 $ , which is the minimal available value. We first choose  $ i=1,j=2 $  to paint and then choose  $ i=2,j=3 $  to paint. After that, cells  $ 1,2,3 $  are painted black, only cell  $ 2 $  is not in the given list, which satisfies the condition  $ x=1 $ .

### 思路分析

#### 1. 二分答案与单调性
题目要求求出满足条件的最小 $k$ 值。注意到操作允许任意次数且允许重复涂黑同一个格子：若某个距离上限 $k$ 能够完成涂色方案，则对于任意更大的 $k' > k$，原方案中的所有操作依然合法，因此 $k'$ 必定也可行。这说明可行性关于 $k$ 具有单调性，可以通过二分答案求解。

由于每次操作必须选择两个**不同**的格子（$1 \le |i - j| \le k$），故二分下界 $l = 1$；坐标满足 $0 \le a_i \le 10^9$，因此答案的上界不超过 $V = 10^9$（或 $a_n - a_1$）。

#### 2. 合法性判定 $\text{check}(k)$
对于固定的 $k$，记我们最终要求涂黑的点集为 $S$（由 $\text{arr}$ 中的全部 $n$ 个点与至多 $x$ 个不在 $\text{arr}$ 中的额外点组成）。构造无向图 $G_k(S)$：若两点 $u, v \in S$ 满足 $1 \le |u - v| \le k$，则在两者之间连边。

$S$ 能够被完整涂黑且不波及外部格子的**充要条件**是：**$G_k(S)$ 中不存在大小为 $1$ 的孤立点（每个点在 $S$ 中至少有一个邻居）**。
- **必要性**：若某点 $u \in S$ 在 $S$ 内没有任何距离不超过 $k$ 的点，则任何包含 $u$ 的合法操作都必然会把 $S$ 外部的格子涂黑，违背题意。
- **充分性**：由于题目允许对已涂黑的格子重复涂黑，只要每个 $u \in S$ 都能在 $S$ 内找到至少一个邻居 $v$ 满足 $1 \le |u - v| \le k$，对每条存在连边的点对各执行一次操作即可涂黑整个 $S$。

基于上述充要条件，$\text{check}(k)$ 的贪心验证分为以下两步：

1. **标记原数组内部的非孤立点（$\text{alive}$ 与 $\text{rest}$）**：
   由于 $\text{arr}$ 严格递增，一个点 $\text{arr}[i]$ 在 $\text{arr}$ 内部存在邻居，当且仅当它与左侧或右侧相邻元素的距离不超过 $k$。因此，遍历所有 $1 \le i < n$，只要满足 $\text{arr}[i+1] - \text{arr}[i] \le k$，就将 $\text{alive}[i]$ 与 $\text{alive}[i+1]$ 均标记为 `true`（注：与 CF2026B 不同，本题允许重复涂黑，因此连通块大小可以大于 $2$，标记后不能直接跳过右侧元素，以免阻塞 $\text{arr}[i+1]$ 与 $\text{arr}[i+2]$ 的连接）。
   之后收集所有 $\text{alive}[i] = \text{false}$ 的元素按升序存入 $\text{rest}$，它们即为在 $\text{arr}$ 内部无法自我消化的“孤立点”。

2. **贪心分配额外黑点（$\text{ans}$）**：
   对于 $\text{rest}$ 中的任意两个相邻元素 $\text{rest}[i]$ 和 $\text{rest}[i+1]$，因为它们在 $\text{arr}$ 中没有距离 $\le k$ 的邻居，所以必然满足：
   $$\text{rest}[i+1] - \text{rest}[i] > k \ge 1$$
   考虑任意一个不在 $\text{arr}$ 中的额外黑点 $z \in [0, 10^9]$：在区间 $[z - k, z - 1]$ 与 $[z + 1, z + k]$ 内，各自至多只能包含 $1$ 个孤立点（若同一侧存在两个孤立点，它们的距离必 $\le k - 1 < k$，与孤立点间距离 $> k$ 矛盾）。因此，**每个额外黑点至多只能拯救 $2$ 个孤立点**，且这 $2$ 个孤立点在 $\text{rest}$ 中必定相邻（跨过一个孤立点的两点距离严格大于 $2k$）。

   于是从左到右扫描 $\text{rest}$ 进行贪心匹配：
   - **双点共用**：若 $i < \text{sz} - 1$ 且 $\text{rest}[i+1] - \text{rest}[i] \le 2k$，可取 $z = \lfloor (\text{rest}[i] + \text{rest}[i+1]) / 2 \rfloor$。由于 $\text{rest}[i+1] - \text{rest}[i] \ge 2$，必有 $\text{rest}[i] < z < \text{rest}[i+1]$ 且 $z \in [0, 10^9]$；同时 $z$ 也不可能与 $\text{arr}$ 中其他元素重合（若中间夹着其他 $\text{arr}$ 元素，两端距离均 $> k$ 将导致总距离 $> 2k$）。此时仅需 $1$ 个额外黑点（$\text{ans}$ 加 $1$）即可将 $\text{rest}[i], z, \text{rest}[i+1]$ 连成连通块，随后令 `i++` 跳过 $\text{rest}[i+1]$。
   - **单点独立**：否则 $\text{rest}[i]$ 无法与右侧孤立点共用黑点，只能单独消耗 $1$ 个额外黑点（$\text{ans}$ 加 $1$），选取 $\text{rest}[i] + 1$ 或 $\text{rest}[i] - 1$ 即可（由孤立性与 $k \ge 1$ 可知相邻位置必不在 $\text{arr}$ 中，且至少有一侧处于 $[0, 10^9]$ 内）。

   由于每个孤立点仅可能与左右相邻孤立点配对，原问题等价于若干条链上的最大匹配，从左到右能合则合的贪心策略一定最优。最终判断所需额外黑点总数是否满足 $\text{ans} \le x$。

### 复杂度分析

- **时间复杂度**：设坐标值域上界为 $V = 10^9$，单组测试数据二分迭代 $O(\log V)$ 次，每次调用 $\text{check}(k)$ 线性扫描 $\text{arr}$、$\text{alive}$ 与 $\text{rest}$ 的时间复杂度为 $O(n)$，故单组时间复杂度为 $O(n \log V)$。所有测试数据总时间复杂度为 $O(\sum n \log V)$。
- **空间复杂度**：使用全局数组 `arr`、`alive` 以及局部数组 `rest`，所需空间均为线性，空间复杂度为 $O(n)$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MAXN = 200005;

int n, x;
int arr[MAXN];
bool alive[MAXN];

bool check(int k) {
    for (int i = 1; i <= n; i++) alive[i] = false;
    for (int i = 1; i < n; i++) {
        if (arr[i + 1] - arr[i] <= k) {
            alive[i] = true;
            alive[i + 1] = true;
        }
    }

    vector<int> rest;
    for (int i = 1; i <= n; i++) {
        if (!alive[i]) rest.push_back(arr[i]);
    }

    int sz = rest.size();
    int ans = 0;
    for (int i = 0; i < sz; i++) {
        if (i < sz - 1 && rest[i + 1] - rest[i] <= 2 * k) {
            ans++;
            i++;
        } else {
            ans++;
        }
    }
    return ans <= x;
}

void solve() {
    cin >> n >> x;
    for (int i = 1; i <= n; i++) cin >> arr[i];

    int l = 1, r = n, ans = r;
    while (l <= r) {
        int mid = (l + r) >> 1;
        if (check(mid)) {
            r = mid - 1;
            ans = mid;
        } else {
            l = mid + 1;
        }
    }

    cout << ans << '\n';
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```
