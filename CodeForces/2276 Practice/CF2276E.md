# CF2276E Good Substrings

## 题目描述

给定一个长度为 $n$ 的字符串 $s$，仅由数字组成。

字符串 $s$ 的子串指的是其字符的连续子序列。对于任意子串 $s_{l\dots r}$，如果它包含字符串 $2025$ 作为子序列，且不包含字符串 $2026$ 作为子序列，则这个子串是坏的；否则，这个子串是好的。例如，字符串 $2025$、$72707275$、$20625$ 是坏的，但字符串 $20256$、$2026$、$777$、$1290723576$ 是好的。

对于每一个 $1$ 到 $n$ 的下标 $i$，请你计算包含该下标的好子串的个数。也就是说，对于每个 $i$，计算所有满足 $1 \leq l \leq i \leq r \leq n$ 且 $s_{l\dots r}$ 是好子串的整数对 $(l, r)$ 的数量。

## 输入格式

第一行包含一个整数 $t$（$1 \leq t \leq 10^4$），表示测试用例的数量。

每个测试用例的第一行包含一个整数 $n$（$1 \leq n \leq 3 \cdot 10^5$）。

每个测试用例的第二行包含一个长度为 $n$ 的字符串 $s$，仅由数字组成。

输入有额外约束：所有测试用例中 $n$ 的总和不超过 $3 \cdot 10^5$。

## 输出格式

对于每个测试用例，输出 $n$ 个整数，第 $i$ 个整数表示包含下标 $i$ 的好子串的数量。

## 输入输出样例 #1

### 输入 #1

```
2
6
202516
5
20265
```

### 输出 #1

```
4 8 10 10 9 6 
5 8 9 8 5
```

### 思路分析

#### 1. 固定左端点与坏子串区间

对于固定的左端点 $l$（$1 \le l \le n$），随着右端点 $r$ 向右移动，子串 $s_{l\dots r}$ 所包含的子序列集合单调递增。因此，存在两个临界位置（均由 `get_point` 求得）：

- $\text{point}_1$：最小的 $r \ge l$，使得 $s_{l\dots r}$ 包含子序列 `2025`；若不存在，记为 $n + 1$。
- $\text{point}_2$：最小的 $r \ge l$，使得 $s_{l\dots r}$ 包含子序列 `2026`；若不存在，记为 $n + 1$。

由单调性可知，以 $l$ 开头的子串 $s_{l\dots r}$ 的合法性完全由 $r$ 所处的区间决定：
- 当 $r < \text{point}_1$ 时，不包含 `2025`，为**好子串**；
- 当 $\text{point}_1 \le r < \text{point}_2$ 时，包含 `2025` 且不包含 `2026`，为**坏子串**；
- 当 $r \ge \text{point}_2$ 时，包含 `2026`，为**好子串**。

因此，当且仅当 $\text{point}_1 < \text{point}_2$ 时，以 $l$ 开头存在坏子串，且坏子串的右端点构成连续区间 $[\text{point}_1,\ \text{point}_2 - 1]$。

#### 2. 贪心匹配与 `nxt` 数组预处理

为了在 $O(1)$ 时间内求得给定左端点 $l$ 的 $\text{point}_1$ 与 $\text{point}_2$，倒序预处理转移数组 `nxt`：
- `nxt[i][d]` 表示在后缀 $s_{i\dots n}$ 中，数字 $d$ 首次出现的位置（若不存在则为 $n + 1$）。
- 递推关系为：先令 `nxt[i] = nxt[i + 1]`，再将当前字符更新为 `nxt[i][s[i] - '0'] = i`。

在 `get_point(l, pat)` 中，按顺序匹配模式串 `pat5`（`2025`）或 `pat6`（`2026`）的每一位：每一步直接跳到当前位置 `poi` 之后最早出现的目标数字 `nxt[poi][pat[k]]`，并在匹配前 3 位后令 `poi++`（保证后续字符严格位于当前字符右侧）。

**正确性说明**：采用调整法即可证明该贪心策略的最优性。任取一组合法匹配下标 $j_1 < j_2 < j_3 < j_4$（$j_1 \ge l$），将 $j_1$ 替换为 $\ge l$ 的首个对应字符 $j_1'$ 后，仍有 $j_1' \le j_1 < j_2$，匹配依然合法且右端点 $j_4$ 不变；依次对 $j_2, j_3, j_4$ 作同样替换，最终右端点不会变大。因此逐步选取最靠左的可行位置必然得到最小的右端点。

#### 3. 一次函数差分统计答案

对每个左端点 $l$，统计以 $l$ 开头的好子串对各个下标 $i$ 的覆盖次数，可拆为“默认全为好子串”与“减去坏子串贡献”两部分：

1. **默认贡献**：若以 $l$ 开头的所有子串均为好子串，则对任意 $i \in [l, n]$，所有右端点 $r \in [i, n]$ 均覆盖下标 $i$，共 $n - i + 1$ 个，即关于 $i$ 的一次函数：
   $$f_0(i) = (-1)\cdot i + (n + 1), \quad i \in [l, n]$$
2. **修正坏子串**（仅当 $\text{point}_1 < \text{point}_2$ 时）：右端点在 $[\text{point}_1, \text{point}_2 - 1]$ 的坏子串覆盖下标 $i$（$i \ge l$）的充要条件为 $i \le r$，故覆盖次数按 $i$ 的位置分两段扣除：
   - 当 $i \in [l, \text{point}_1 - 1]$ 时，所有坏子串均覆盖 $i$，应减去常数 $\text{point}_2 - \text{point}_1$，即加上一次函数：
     $$f_1(i) = 0 \cdot i + (\text{point}_1 - \text{point}_2)$$
   - 当 $i \in [\text{point}_1, \text{point}_2 - 1]$ 时，覆盖 $i$ 的坏子串右端点为 $r \in [i, \text{point}_2 - 1]$，共 $\text{point}_2 - i$ 个，应加上一次函数：
     $$f_2(i) = 1 \cdot i + (-\text{point}_2)$$
   - 当 $i \ge \text{point}_2$ 时，无坏子串覆盖 $i$，修正量为 $0$。

由于一次函数满足线性可加性：
$$(k_1 i + m_1) + (k_2 i + m_2) = (k_1 + k_2)i + (m_1 + m_2)$$
使用两个一阶差分数组 `cfk` 与 `cfm` 分别维护一次项系数 $k$ 与常数项 $m$。通过 `add(L, R, k, m)` 即可在 $O(1)$ 时间内完成任意区间上的一次函数叠加。最终对 `cfk` 与 `cfm` 从左到右求前缀和得到 `sum_k` 与 `sum_m`，每个位置 $i$ 的答案即为 $\text{sumK} \cdot i + \text{sumM}$。

---

### 复杂度分析

- **时间复杂度**：单组数据中，倒序预处理 `nxt` 数组需要 $O(10n)$；枚举 $n$ 个左端点 $l$ 时，每次 `get_point` 最多跳转 $4$ 步，每次 `add` 为 $O(1)$，耗时 $O(n)$；最后扫描求前缀和并输出为 $O(n)$。结合 $\sum n \le 3 \cdot 10^5$，总时间复杂度为 $O(\sum n)$。
- **空间复杂度**：`nxt` 数组占用 $O(10n)$ 空间，差分数组 `cfk` 与 `cfm` 占用 $O(n)$ 空间，单组数据空间复杂度为 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
constexpr int MAXN = 300005;

void solve() {
    int n;
    string s;
    cin >> n >> s;
    s = " " + s;

    vector<int> cfk(n + 5, 0), cfm(n + 5, 0);
    vector<array<int, 10>> nxt(n + 5);
    nxt[n + 1].fill(n + 1);
    for (int i = n; i >= 1; i--) {
        nxt[i] = nxt[i + 1];
        nxt[i][s[i] - '0'] = i;
    }

    int pat5[4] = {2, 0, 2, 5}, pat6[4] = {2, 0, 2, 6};
    auto get_point = [&](int l, int pat[4]) -> int {
        int poi = l;
        for (int k = 0; k < 4; k++) {
            poi = nxt[poi][pat[k]];
            if (poi > n) return n + 1;
            if (k < 3) poi++;
        }
        return poi;
    };

    auto add = [&](int L, int R, int k, int m) -> void {
        if (L > R) return;
        cfk[L] += k;
        cfk[R + 1] -= k;
        cfm[L] += m;
        cfm[R + 1] -= m;
        return;
    };

    for (int l = 1; l <= n; l++) {
        add(l, n, -1, n + 1);
        int point1 = get_point(l, pat5);
        int point2 = get_point(l, pat6);
        if (point1 < point2) {
            add(1, point1 - l, 0, point1 - point2);
            add(point1, point2 - 1, 1, -point2);
        }
    }

    int sum_k = 0, sum_m = 0;
    for (int i = 1; i <= n; i++) {
        sum_k += cfk[i];
        sum_m += cfm[i];
        cout << sum_k * i + sum_m << ' ';
    }
    cout << '\n';
    return;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```
